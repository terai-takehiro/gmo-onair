# Kairos3（MA）の登録通知メール — 読み取り方

差出人は **`Kairos3-NOTIFICATION@kairos3.com`** の1つだけ。
`To: kakeda-shugo@`、`Cc: info@gmo-globalstudio.com`
（お問い合わせだけ Slack のメール連携アドレスにも Cc）。

## どのフォームかの見分け方

**件名**が `登録通知 - <フォーム名>【会社名】` の形です。加えて本文の末尾に

```
※このメールは、登録通知ルール｢<ルール名>｣による登録通知メールです。
```

があり、**このルール名が一番確実な手がかり**です。

| フォーム | 件名に入る語 | ルール名 |
|---|---|---|
| お問い合わせ | `お問い合わせ` | `【要対応】問合せフォーム登録` |
| 資料ダウンロード | `資料ダウンロードフォーム` | `資料ダウンロード` |
| 定期内覧会 来場予約 | `定期内覧会_来場予約フォーム` | （回ごとに変わる） |

## 本文の形（3フォーム共通）

`[ラベル]` の次の行が値です。**値が空の行も出ます**（空欄で送られた項目）。

```
キャンペーン ｢お問い合わせ｣ に登録がありました。
https://web.samurai-studio.gmo/form/contact

登録者情報

[名前]
村上 亮太
[ふりがな]

[メールアドレス]
rmurakami@bushiroad.com [NEW]
[会社情報]
株式会社ブシロードムーブ [NEW]
[郵便番号]

[住所]

[電話番号]

[FAX番号]

[携帯番号]
09048087679
[役職]
経営者/役員
[メール配信可否]
承諾

[スコアレポート] https://kairos3.com/r_score?customer=2837
[リード編集] https://kairos3.com/l_manage?action=cust_edit&customer_id=2837
[会社編集] https://kairos3.com/l_manage_segment?type=company&edit=1&company=1137

その他回答など

[お問い合わせ対象の会場]
GMOサムライスタジオ 用賀
...
```

- **`[NEW]` が付いている値は Kairos3 側で新規**です。初回接触かどうかの判定に使えます。
- `[スコアレポート]` `[リード編集]` `[会社編集]` は Kairos3 の管理画面へのリンクです。
  **`record_*` の `url` にはこれを入れないこと** — 押した人が Kairos3 にログインしていないと
  行き止まりになります。
- **空欄の項目は渡しません。** 「電話番号: （空）」を入れると、
  読み取れなかったのか本当に空なのかが区別できなくなります。

## フォームごとの追加項目（`その他回答など` の中）

### お問い合わせ

| 項目 | 使い道 |
|---|---|
| `[お問い合わせ対象の会場]` | 案件の会場。`GMOサムライスタジオ 用賀` など |
| `[お問い合わせ種別]` | 「空き状況の確認」「見積依頼」など。**活動記録の見出しに使う** |
| `[お問い合わせ内容]` | 自由文。**要件・希望日・人数・予算がここに入る**。全文を `body_text` に |
| `[このサイトへお越しいただいたきっかけを教えてください]` | リード経路 |

**呼び方**（`idempotency_key` を意図別に分けること）:

```
create_project(
  name        = 「<会社名> <お問い合わせ種別>」,
  customer_*  = 会社名・担当者名・メール・電話,
  stage       = neta,
  message_id  = <メールの Message-ID>,
  source_channel = 'info@',
  idempotency_key = 'email:<msgid>:project',
)
create_activity_log(
  project_id  = 上で作った案件,
  ...お問い合わせ内容を整形...,
  idempotency_key = 'email:<msgid>:activity',
)
```

⚠️ **`create_project` は `assigned_to`（`users.id`）が必須**です。
`list_users` で解決してから渡します。分からないときは営業の既定担当を使い、
**適当な人を当てないこと**（通知がその人に飛びます）。

### 資料ダウンロード

| 項目 | 使い道 |
|---|---|
| `[ダウンロードを希望する資料]` | 何に興味があるか。複数行のことがある |
| `[興味がある会場]` | 会場 |
| `[資料ダウンロードの目的を教えてください]` | **ここで案件にするかを分ける**（決定表 #5） |
| `[このサイトへお越しいただいたきっかけを教えてください]` | リード経路 |

### 定期内覧会 来場予約

| 項目 | 使い道 |
|---|---|
| `[参加希望の回]` | **`session_label` にそのまま渡す**。日付・時間帯・対象はサーバーが抽出する |
| 同行者の氏名 | `companions` |

```
register_inview_attendee(
  session_label = '<[参加希望の回] の値をそのまま>',
  name / furigana / email / company / role / phone / mobile / mail_consent,
  companions = [...],
)
```

**同じ email × 同じ `session_label` は更新**されます（再取込で重複しません）。
`session_label` を自分で言い換えないこと — 言い換えると別の回として登録されます。

# 実アプリ画面のスクリーンショット置き場

ここに以下のファイル名で PNG（または jpg/webp）を置いて `build_deck.py` を実行すると、
資料の各「画面」が**自動的に本物のスクリーンショットに差し替わります**。
置かれていない画面は、これまで通り高精細なUIモックアップで描画されます。

| ファイル名 | 対応アプリ | おすすめの画面 |
|---|---|---|
| `projects.png`  | 案件管理 | ダッシュボード（KPI＋グラフが見える画面） |
| `qsheet.png`    | Qシート | ランダウン or OnAir 画面 |
| `equipment.png` | 機材管理 | 機材一覧テーブル |
| `techsheet.png` | 技術資料 | 仕様シートの編集画面 |
| `live.png`      | ライブ運用 | タイマー＋視聴者数の本番画面 |
| `cg.png`        | リアルタイムCG | 送出出力（テロップ/ランキング） |

## 撮り方のコツ
- 解像度はそのままでOK（自動で枠にフィット＝cover で配置、左右 or 上下を少しトリミングします）。
- 横長（16:9〜16:10）で撮るとブラウザ枠にきれいに収まります。
- 個人情報・実在の取引先名などが映る場合は、ダミーデータの検証環境（dev）推奨です。

## 再生成
```bash
python3 docs/presentation/build_deck.py
```

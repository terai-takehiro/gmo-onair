# 実機での総点検チェックリスト（R5 層3・ユーザー実施）

**対象**: https://dev.gmo-onair.jp （検証環境。壊してよい）
**端末**: iPhone（縦持ち）と iPad（横持ち）。Safari で開く（WebKit の挙動が層1・層2では見えないため）。
**前提**: 層1（verify:ui 機械検査・89画面×3幅）と層2（スクショ267枚の目視・ギャラリー）は実施済み。
ここで見るのは**機械とスクショでは分からないもの**だけ — 触った手応え・遷移の流れ・実機フォント・safe-area・ダークモード。

結果は各行のチェックを付け、気づきはこのファイルに書き足すか、チャットで共有してください。
**崩れを見つけたら「画面名・端末・何をしたら・どう見えたか」の4点**があれば直せます（スクショがあればなお良い）。

## A. 全アプリ共通（最初に1回）

- [ ] **下タブと safe-area**: iPhone でどのアプリでも、下端のタブ・主ボタンがホームバーと重ならない
- [ ] **ダークモード**: OS をダークにして一巡 — 読めない文字・白いままの面がないか
  （v4 は明るい配色が基本。**制作技術支援の本番系（OnAir・ランダウン・プロンプター）だけが暗い画面**で正しい）
- [ ] **タップの手応え**: ボタンを押した瞬間に少し縮む（0.97倍）。押しても無反応に見える場所がないか
- [ ] **回転**: iPad で縦⇄横に回してレイアウトが壊れないか（特に一覧と詳細）
- [ ] **文字**: 全体が LINE Seed JP で出ているか（明朝やヒラギノに落ちている画面がないか）
- [ ] **スクロール**: 画面全体が横に揺れる（左右に数px動く）ページがないか

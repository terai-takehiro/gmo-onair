## 依頼1【新規】費用を分け合う請求 — グループ合同案件

### やりたいこと（業務）

グループ会社の合同イベントを1回開き、**かかった費用を参加した会社で分けて、各社に請求書を出します。**

> 例：**株主総会をグループ9社で合同開催**する。費用の総額を出して**9等分**し、**9社それぞれに請求書**を出す。

- 分け方は**均等が基本**ですが、均等でないこともあります
- **請求書は参加社数ぶん**（この例では9枚）必要です
- どの会社が払っていないかを追う必要があります
- 全体としていくら儲かったかも見たいです

### いまの実装（事実）

すでに「費用を分け合う」仕組みはあり、**現役で使っています**。ただし**向きが違います**。

| したいこと | いまできるか |
| --- | --- |
| 費用を分け合う案件のまとまりを作る | **できる** |
| 総額を均等 or 任意の金額で分ける | **できる**（端数は先頭の案件に寄せている） |
| 分けた金額を各案件の売上・仕入・粗利に反映する | **できる** |
| **各社に請求書を出す（9枚）** | **できない** |
| **合同用の見積を全体で1本つくって分ける** | **できない** |
| どの会社が払っていないかを追う | できない |
| 全体の粗利を見る | できない |

**なぜ請求書が9枚出せないか**（作りの話を1行で）

> いまの仕組みは「**1件の売上**に**請求先を1社**だけ持ち、その金額を**9つの案件**に分けて配る」形です。
> つまり「**払うのは1社。費用を9案件で分け合う**」を表しています。
> 業務は「**9社がそれぞれ払う**」なので、**同じ道具では表現できません**。

いまこの業務をやろうとすると、**9件を手で作る**ことになります（1社ぶん作るたびに宛名と金額を入れ直す）。
9社が10社になれば作業も1社ぶん増えます。ここをデザインしてほしいです。

### 欲しい画面（要件）

1. **まとまりを作る**
   - イベント名（例：2026年 定時株主総会）
   - **費用を分け合う会社を選ぶ**（9社）。**案件を9個手で作らせないでください**
   - 主催・幹事の会社が分かるようにしたい（取りまとめる相手）

2. **総額を1回だけ入れる**
   - 見積は**全体で1本**。（30章でつくった見積画面をそのまま使えるとうれしいです）
   - 明細のグループ（スタジオ / 技術・人員 / 制作・その他）と仕入の列もそのまま使いたい

3. **分け方を選ぶ**
   - **均等**（9等分）／**比率**（社員数・持分など）／**金額を直接入れる** の3つ
   - **端数の行き先を画面に出す**（いまは黙って先頭の案件に寄せています。1円の差が誰に付くのか見えません）
   - 分けた結果を、各社の金額が並ぶ表で見せてほしい

4. **確認して、まとめて出す**
   - 各社の「宛名・金額・支払期日」が並ぶ確認の表
   - **「まとめて出す」で参加社数ぶんの請求書**（この例では9枚）
   - 1社だけ金額を直したいこともあります（直したら合計が総額に合っているかを画面で示す）

5. **入金を追う**
   - **どの会社が未入金か**が一目で分かる（31章「請求と入金」と同じ見た目でお願いします）

6. **全体の数字を見る**
   - 9社合計の 売上 / 仕入 / 粗利。1社ぶんだけ見ても全体が分かりません

### デザインで決めてほしいこと

| 論点 | 補足 |
| --- | --- |
| **入口はどこか** | 「お金」の中／案件の中／独立した場所 のどれか。レールは6項目のままにしたいので、増やさない形でお願いします |
| **いまの形（1社が払って費用を分ける）も残すか** | 残すなら**画面でどう区別するか**。同じ画面に2つの意味が混ざると必ず間違えます |
| **分け方の既定** | 均等でよいか |
| **端数の見せ方** | 1円をどこに付けるか、画面に出す形 |
| **請求書を出したあとに1社抜けたとき** | 直し方（出した請求書は消せません） |
| **呼び名** | 「按分」は会計用語なので画面に出したくありません（依頼5と同じ話）。何と呼ぶか |

### 参考（作りの制約として知っておいてほしいこと）

- **金額は税抜で持ちます。** 消費税と支払額は表示のときに足します
- **請求書の番号（billing_key）は1枚ごとに採ります。** 9枚出せば9本の番号が付きます
- 分けた金額は**そのまま各案件の粗利に効きます**。だから「分け方」は数字の正しさに直結します

## 依頼2【修正】14章 27a の「やめる」から「グループ区分」を外してください

### お願い

「やめる（4項目）」から **グループ区分** を外し、**3項目**にしてください。

| 項目 | 判断 |
| --- | --- |
| ~~グループ区分~~ | **やめない。現役で必要**（依頼1のとおり、グループ合同案件の請求に使っています） |
| 案件種類（その他） | 削除で合意 |
| タグ | 削除で合意 |
| 教訓・学び | 削除で合意（ふりかえりに書きます） |

### あわせて2点、確認したいこと

1. **案件フォームに「グループ区分」という入力欄は、実装に存在しません。**
   費用を分け合う設定は案件フォームではなく**別の画面**にあります。
   27aは「案件フォームの22項目」を仕分けたものなので、**別の項目と混ざっている可能性**があります。
   （もし「案件フォームの中で費用を分け合う設定をしている」前提で描かれているなら、その前提が実装と違います）

2. **「進んだら聞く」の件数が合っていません。**
   見出しは **9項目**ですが、中に並んでいるのは **7項目**です。
   （本番日・リハ日／使用する部屋／想定金額／追加の日程／申込書・ロゴ使用許諾／主担当／失注理由）
   2項目が抜けているか、件数の書き間違いだと思います。**どちらか教えてください。**

### 14章そのものについて（お礼と1つのお願い）

14章「案件の入力を減らす（22項目 → 起票は3つ）」は、**これまでの実装計画に1行も入っていませんでした**。
突き合わせて初めて気づいたもので、**毎日いちばん多く触る入力**なので優先して作りたいです。

そのうえで1つだけ：**27cの「進んだ段で聞く」の中身**（どのステージで、どの項目を、なぜ聞くか）が
デザインの中では表になっているのに具体の値が入っていません。**ここを埋めていただけますか。**
「受注のときに申込書を聞く」のような1対1の対応が要ります。

## 依頼3【修正】29章 隔週キープの配布は PDF だけにしてください

いまのデザインは「配布は **PDF と PowerPoint** の両方」となっています。
**PDFだけで足ります。** PowerPoint出力は作らない方針にしたいです。

- 投影も配布もPDFで済むため
- PowerPointを作る仕組みは追加で必要になり、そのぶんを他の章に回したいため

29章の該当箇所（出力の説明）を **「投影はそのまま、配布はPDF」** に直してください。

## 依頼4【削除】24c「リハーサルと本番を分ける」は不要です

**リハーサルと本番を分ける概念を持ちません。** 24cは削除してください。

20章（リアルタイムCG）の他の画面（24a 送出1画面 / 24b 出力URLの配り方 / 24e アワードだけ実装 /
24f データを入れる / 24d スマホは見張るだけ）は**そのまま進めます。**

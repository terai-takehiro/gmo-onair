# docs/archive — 役目を終えた文書の置き場

- **役目を終えた日付付き文書**をここへ移す。置き場は `docs/archive/<年>/<元の名前>.md`（サブディレクトリは年の下に平らに置き、紛らわしい名前は `architecture-` のように元の場所を前置する）。
- 元の場所がルート `CLAUDE.md` / `README.md` など**このリポジトリの運用上すぐ直せないファイルから参照されている場合だけ**、元の場所に1行ポインタ（スタブ）を残す。
- **追記型の台帳は対象外**: `docs/version-history.md`・`docs/reviews/codex-findings-v4.md`・`docs/changelog.d/` はアーカイブへ移さない。
- 中身は当時のまま残す（リンクの張り替えは移動で切れる分だけ直す。内容の手入れはしない）。

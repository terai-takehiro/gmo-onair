## ストリーム URL（プリセットに組み込み済み・1字も変えない）

| 用途 | URL |
| --- | --- |
| プライマリ（RTMP） | `rtmp://a.rtmp.youtube.com/live2` |
| バックアップ（RTMP） | `rtmp://b.rtmp.youtube.com/live2?backup=1` |
| プライマリ（RTMPS） | `rtmps://a.rtmps.youtube.com:443/live2` |
| バックアップ（RTMPS） | `rtmps://b.rtmps.youtube.com:443/live2?backup=1` |

## 推奨エンコーダ設定（answer 2853702）

共通: プロトコル RTMPS / RTMP・動画 H.264・**キーフレームの頻度 2 秒を推奨（4 秒を超えない）**・
**CBR（固定ビットレート）**・音声 **AAC・44.1 kHz・128 Kbps ステレオ**。
解像度とフレームレートは既定で**自動検出**（手動指定はカスタムストリームキー作成時のみ）。

| 解像度・フレームレート | 推奨ビットレート (Kbps) |
| --- | --- |
| 2160p (4K) 60fps | 20,000〜51,000 |
| 2160p (4K) 30fps | 13,000〜34,000 |
| 1440p (2K) 60fps | 9,000〜18,000 |
| 1440p (2K) 30fps | 6,000〜13,000 |
| 1080p 60fps | 4,500〜9,000 |
| 1080p 30fps | 3,000〜6,000 |
| 720p 60fps | 2,250〜6,000 |
| 720p 30fps | 1,500〜4,000 |
| 480p | 500〜2,000 |
| 360p | 400〜1,000 |
| 240p | 300〜700 |

（画面に出すのは現場で使う 2160p〜720p の6段だけ。HDR / HEVC / AV1 の表は
公式ページを見て確かめてから足すこと — ここには未検証の数値を書かない）

## YouTube Studio 側で設定する項目（機器からは変えられない）

配信設定の欄にはしない — 機器から変えられない設定を欄として置くと
「打てるのに反映されない欄」になる（#279 の判断）。画面では YouTube の配信先を
選んだときに「YouTube 配信の決めごと」として**確認リスト**で出す。

| YouTube Studio の表記 | 選択肢・意味 |
| --- | --- |
| タイトル / 説明 / カテゴリ | 最大 100 文字 / — / — |
| 公開設定 | **公開 / 限定公開 / 非公開** |
| 視聴者 | 「この動画は子ども向けですか？」**はい / いいえ**（＋年齢制限の詳細設定） |
| ストリームキーを選択 | 既定キー（自動生成・解像度自動検出）か「新しいストリームキーを作成」 |
| ストリームキー | **コピー / リセット**（漏れたらリセットで無効化） |
| 配信の遅延 | **通常の遅延 / 低遅延 / 超低遅延**（4K は通常の遅延のみ） |
| DVR を有効にする | 視聴者が一時停止・巻き戻しできる |
| 360°動画 / 字幕 | スタジオの SDI 運用では通常使わない |
| 配信終了後、公開されたライブ配信のアーカイブを限定公開にする | トグル |
| チャット | 有効 / リプレイ / メンバー限定 / 低速モード / 確認のために保留 |
| ライセンス | 標準の YouTube ライセンス / クリエイティブ・コモンズ – 表示 |

## 画面へどう反映したか（2026-08-30）

- **配信先プリセット**（YouTube プライマリ / バックアップ / カスタム入力）を
  インスペクタと一覧に追加。中身・判断は現地の Assistant（`stream/presets.ts`）と同じ:
  URL だけ入れる・キーはプリセットで動かさない・選んだ値は覚えず URL から逆引き
- YouTube の URL を選ぶと「**YouTube 配信の決めごと**」（推奨設定の要点＋ビットレート表＋
  Studio 側の確認リスト）が畳んで出る（`DestinationInspector.tsx`）
- 値は `shared/tests/streamPresets.test.ts` で固定（URL・1080p の推奨値）

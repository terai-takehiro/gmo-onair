# テロップCG デザイン実測仕様（ピクセル基準）

**2026-08-30 ディープリサーチ3本（報道系・バラエティ/式典系・画面レイアウト規格）の統合。**
テロップCG（[graphics.md](graphics.md)）の部品 CSS・文字スタイルプリセット・キャンバスガイドの
**数値の正**はこの文書。AI が雰囲気で作るテロップを排し、実際の放送の作法を数値で固定する。

確度の凡例: **【規格】**=規格文書で確定 ／ **【実務】**=複数ソース一致の業界相場 ／
**【推定】**=傾向からの合成値（実機検証で締める）。出典は各節末。

---

## 0. キャンバスとセーフエリア【規格】

論理キャンバスは **1920×1080 固定**（4K は `scale(2)` の整数倍出力。%で持てば解像度非依存）。

| ガイド | 座標 | 用途 |
|---|---|---|
| 文字セーフ 90% | (96, 54) – (1824, 1026) | **常駐物・重要文字の既定枠**。ARIB旧/SMPTE ST 2046-1/EBU R95 が一致 |
| アクションセーフ 93% | (67, 38) – (1853, 1042) | 映像的要素の限界 |
| ARIB目標 文字 95% | (48, 27) – (1872, 1053) | 現行番組の攻め位置（配信のみならここまで可） |
| 字幕放送想定域 | x 360–1560, y 880–1026 | 字幕付与番組では恒久物を避ける参考枠 |

- 4:3 セーフは**原則考慮不要**（地デジ移行後の実務で撤廃済み）
- テレビはいまだ出荷時オーバースキャン ON が多い → **テレビ送出兼用は 90% 厳守**、
  配信専用レイヤーだけ 95% まで攻めてよい
- **持ち場のルール【実務】**: 左上=時刻（下に LIVE バグ）／右上=局ロゴ・サイドスーパー／
  下部=テロップ帯・字幕。速報時は上辺。互いの持ち場に入らない

CSS 定数: `--safe-x:96px; --safe-y:54px; --safe-stream-x:48px; --safe-stream-y:27px`

## 1. 書体【実務】

- **報道・情報の本文は UD系角ゴシック一択**。実在の採用: NHK=UD新ゴ（2023 UD刷新）、
  テレ朝=テレ朝UD（UD角ゴ_ラージベース）、フジ=UD新ゴ系、日テレ=ニューロダン
- 明朝は普通の明朝ではなく**横太明朝**（フォントワークス「テロップ明朝」= 筑紫明朝の横画を
  太らせた画面用）。通常明朝は横線が細く画面でちらつく → 式典系も**太ウェイトの明朝**を選ぶ
- **疑似ボールド（faux bold）は禁忌**（ずらし重ねで画が潰れる）。必ず実ウェイト。
  CSS: `font-synthesis: none` を全部品に必須
- 同梱書体での割当（ライセンス安全圏）: 角ゴ=LINE Seed JP（400/700/800）＋
  Noto Sans JP（UD系の代替・500/600 が要るとき）、横太明朝の代替=Noto Serif JP の 700–900
- ウェイト相場: 報道本文 DB〜B（CSS 500–700）、氏名・見出し 700–800

## 2. 文字サイズの階層（px @1080）【実務】

| 階層 | px | 用途 |
|---|---|---|
| 題字・強調 | 90–120（強調は基準の1.5–2倍） | 式典題字・大見出し |
| 見出し | 60–80 | サイド見出し・コーナー |
| メイン | 48–60（基準 ≒ 画面縦の6–8%） | 発言テロップ・本文 |
| 字幕系 | 42–48 | 下部字幕 |
| 補足 | 36–42 | 肩書・出典・注記 |
| 絶対下限 | **30（テレビ視聴距離基準。26未満は不可）** | — |

**全文同サイズは素人の典型** — 階層は「位置・大きさ・色/書体」の3軸で作る。

## 3. エッジ（縁取り）・シャドウ・袋文字

- 太さの相場: **文字サイズの 5–10%**（50px文字→片側2.5–5px）。報道は下限寄り（5–7%）、
  バラエティは実測レイヤー: 塗り／内フチ **6–8px**（感情色）／外フチ **14–16px**（黒 #1A1A1A）【実務】
- **多重フチは2重まで**。3重以上・細字に太フチ・**ぼかしたフチ**は名指しのNG【実務】
- エッジ色は文字と**反対の明度**（白文字→黒〜濃紺）。内:外 ≒ 1:2【推定】
- シャドウ: テレビは**ベタ落ち影**（`text-shadow: 8px 8px 0 rgba(0,0,0,.9)`・ぼかし0）か
  短距離ソフト影（`0 3px 8px rgba(0,0,0,.45)`・式典系）。**報道はシャドウ無し〜ごく浅め**。
  全方位グロー・ぼかしすぎは素人サイン【実務】
- **袋文字のレイヤー順（正）**: 塗り → 内エッジ → 外エッジ → シャドウ → 座布団
- CSS 技術選定【実装】: `-webkit-text-stroke` は1重のみ → **同一テキストを重ね描き**
  （grid 同セル重ね・背面ほど stroke 太く・`paint-order: stroke fill`）が唯一正確。
  `text-shadow` 8方向重ねは太フチで角が割れるのでフチには使わない（影専用）

## 4. 座布団（ベース）

- 不透明度 **50–80%**。ベタ100%は画面を殺す【実務】
- **単色ベタ矩形が素人臭い理由**: 質感ゼロ・余白の詰まり・無関係な彩度。処方は3点セット:
  ①上下で明度差5–10%の縦グラデ（または上10–15%にハイライト帯）
  ②`1px` の明縁 or 暗縁 ③短距離の `box-shadow: 0 4px 12px rgba(0,0,0,.35)` まで【推定】
- 余白: 文字サイズの **左右 0.5–0.75em・上下 0.25–0.4em**【推定】
- 角丸: 報道・式典=スクエア〜4px、バラエティ=大きめ可。**角丸過多は幼く見える**
- 報道の帯色: 半透明黒 `rgba(0,0,0,.5–.7)`・NHK型グレー `rgba(40,40,45,.75)`・
  紺 `#001c50` 系が民放定番【推定】。式典=黒70%＋左端 4px の金アクセントバー

## 5. 色の規範

- 報道: **白＋黒＋アクセント1色が鉄則**。色数の少なさが「報道らしさ」の最大要因。
  赤は速報・緊急**以外に使わない**（速報=赤地白 or 黄地黒の反転）【実務】
- **輝度セーフ**: 純白 #FFF（スーパーホワイト）を避け、白は **#F5F5F5〜#EFEFEF**
  （SDI送出まで見据えるなら 235=#EBEBEB 上限・黒は #101010）。彩度100%の原色も落とす【実務】
- 式典の金【実務】: 上品系 **#D4AF37**（本命）／標準 #FFD700／アンティーク #B8860B／
  シャンパン #F7E7CE。**金は黒・白（または濃紺）と組んで初めて品が出る**
  - 輝く金グラデ: `#FFD700 → #FFF9E6 → #FFD700`
  - 金属感の強い金（Premiere公開レシピのCSS換算）:
    `linear-gradient(180deg,#E8C34A 0%,#FFFDF0 44%,#8A5A0E 52%,#D98E1F 60%,#E8C34A 100%)`
    ＋ `background-clip:text`（グラデ文字は strokeと層を分ける）
- グラデ塗りは**強調語だけ**。小さい文字への縦グラデは可読性を落とす
- バラエティ感情色: 強ツッコミ=赤系／ボケ・笑い=黄〜橙／独白=白明朝＋影のみ（フチ無し）。
  **1本の中でデザイン種類は3〜4種に固定**

## 7. 組版ルール（テレビ的ルール）【実務】

- 1行 **最大18字**（実務は16字×2行以内）。改行は意味の区切り・行頭に助詞を置かない
- **句読点「、」「。」は使わない**（全角スペースで代用）
- 表示時間: `max(2秒, 文字数÷4)` ＋消すのは話し終わりの1拍（0.5秒）後。最低3秒（報道）
- 長体（自動縮小）は **80% が可読性の限界**（`scaleX(.9)` 無難・`.8` まで）
- 文字詰め: 本文=ベタ〜やや詰め（`letter-spacing: -0.02em〜0`）、題字=広め（`0.08–0.2em`）
- 数字は半角・**等幅**（`font-feature-settings:'tnum'`）。桁増減でレイアウトを動かさない
- 見出しはツメ組（`'palt'`）可・本文はベタ寄り

## 8. アニメーションの作法

- バラエティ発言: **カットイン（0フレーム）**が基本。ポップは
  `scale 0→200%(5f)→100%(3f)` ≒ **0.27秒**（オーバーシュート付き easing で代替）。
  通常フォローに毎回アニメを付けるのは素人パターン
- 式典: **フェード 0.5–1.0秒**（カットインは不躾）。ネームは左→右マスク展開 0.6–0.8秒 可。
  表示は最低4秒・`文字数÷6 + 余裕`
- ティッカーのループ・速度は §6。カットの都合より**読み切れること**が優先

## 9. 「AIっぽい／素人っぽい」NG集（部品実装のレビュー基準にする）

1. デフォルト書体のまま・疑似ボールド
2. 1本の中で見た目がバラバラ（統一が最優先）
3. フチが細字に太すぎ／**フチをぼかす**／3重以上のエッジ
4. 彩度100%の原色・色数過多
5. シャドウのぼかしすぎ・距離ゼロの全方位グロー
6. 純白 #FFF（スーパーホワイト）
7. **単色ベタ矩形の座布団**（質感ゼロ）
8. セーフ無視の画面端ギリギリ
9. 全文字同サイズ・メリハリなし
10. 小さい文字への縦グラデ
11. 毎テロップにアニメ・長すぎる出し尺（ポップは0.3秒未満）
12. 角丸過多・字間ゆるすぎ

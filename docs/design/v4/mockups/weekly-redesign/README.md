## 変更点

1. **構成を「生成工程の順」から「読み手の順」へ。** 自動集計 → AI の要約 → 週次トピックス
   ではなく **総括 → 主要指標 → トピックス → 詳細内訳**。見出しは「AI の要約」ではなく
   **「総括」**とし、AI の関与は本文下部の**署名**（AI下書き／編集者）に集約する。
2. **画面見出しを対象週そのものにした。** `◀ 8月31日 〜 9月6日 ▶` に 今週／先週 の表示を添える。
   最初に作成した週の日付に以後が引きずられる状態（検証環境が 7/6 起点のまま停止していた事象）を
   画面側でも解消する。
3. **状態表示を1系統に集約。** 「下書き／確定済み（確定者と時刻）」のみ。
   「確認済み／未確認」は個人の既読状態のため右上の`確認した`に、「AI作成」は署名行に統合する。
4. **未入力時は次に行う操作を提示する。** 空カードを3枚並べず、主要指標を提示したうえで
   「AI下書きを作成」「直接入力する」の2択に絞る。
5. **詳細内訳（パイプライン・営業活動の内訳・イベント・翌週予定）は折りたたむ。**
   閲覧時は不要、作成時は参照データとなるため、下書きの画面では展開する。
6. **対象週の追加・削除。** 日付入力欄の直置きをやめ、月次カレンダーから週行を選択する
   （作成済みの週をその場で判別できる）。削除は行の `⋯` に格納し、確定済みの週は選択不可として
   理由を表示する（サーバー側の制御と同一）。

## 用語

[`docs/wording.md`](../../../../wording.md) のルール6〜9（開くかどうかは通用範囲で決める／
ラベルは12文字まで／動詞は 追加・編集・削除・キャンセル・保存 に固定／基本語で開き口語・造語・
比喩を作らない）に従う。「パイプライン」「トピックス」は業界標準語・既存語のため残す。

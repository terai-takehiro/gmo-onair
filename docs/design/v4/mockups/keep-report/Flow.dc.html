凍結と履歴

パックは会議日ごとの版（keep_report_packs）。週報を確定した時点の数字を凍結し、資料・Slack は必ず凍結した版を読む。構成（keep_decks）は保存のたびに版を残し、前回の版から次回の初期構成を作る。出力した pptx の置き場（Box の file id）も版に記録する。

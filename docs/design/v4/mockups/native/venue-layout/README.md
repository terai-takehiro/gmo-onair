## 下敷きと縮尺（このモックの肝）

下敷き画像（`world-26f.png`・`lounge-27f.png`・`floor-26f.png`・`floor-27f.png`）は図面 PDF を通り芯で**2軸校正**して切り出したもの。
`world-26f.png` はトラス脚の横の ■ 10 個、四隅・前室の黒い矩形 5 つ、建築図面の寸法線と数字を消し込んである（柱の □ は残す。設計書 §4-7。消し込み前の画像は同梱しない）。
値の出どころは設計書 §8・§10（実測: X 63.199 mm/pt・Y 60.577 mm/pt・X/Y の差 4.3%）。

| 下敷き | 1px あたり（X／Y） | 原点（mm） | 使う画面 |
|---|---|---|---|
| `world-26f.png`（800×966） | 25.5mm ／ 24.4mm（pxPerMm 0.039216 ／ 0.040913） | (12,193, 10,995) | 編集・並べる・スマホ・仕上がり（下敷きを出したとき） |
| `lounge-27f.png`（600×1232） | 20.7mm ／ 19.8mm（0.048387 ／ 0.050481） | (27,296, 10,402) | 編集（階とエリアの切替） |
| `floor-26f.png`・`floor-27f.png`（420×584） | 85.7mm ／ 82.2mm（0.011667 ／ 0.012172） | (4,493, −1,525) | 一覧のサムネ |

品目の px は **mm × pxPerMm** で計算している（ルベックチェア 535×490mm → 21.0×20.0px・ズーム 100%）。
下敷きの X/Y の歪みは下敷き画像の中で吸収し、品目は等方の mm 空間に描く（設計書 §8-2）。
画像は Claude Design のキャンバスに同梱している（このフォルダには置かない・`.gitignore`）。

## 色・寸法の出どころ

推測ではなく実装から取った値だけを使っている（`native/production-manual/` と同じ）。

- 色・角丸: `shared/src/client/tokens-v4.css`（`#005bac` `#f7f8fa` `#e6e9ed` `#1a1d24` `#5d6470` `#197a4b` `#c2410e` `#c7243a`）
- 型スケール: `shared/tailwind.preset.ts`（h1 23 / h2 19 / cardtitle 15 / list 13.5 / sub 12.5 / sub-sm 11.5 / badge 11）
- 共通シェル（上辺バー 64・左メニュー 248・編集画面は畳んだ状態）: `native/production-manual/Editor.dc.html`・`Main.dc.html` の写し
- 品目の俯瞰シンボル: 線画・単色・薄い塗り・正面は −y（設計書 §4・§11）
- 備品の寸法: GMOサムライスタジオ 用賀 備品リスト（最終更新 2026.05.13）。昭特のカメラは検索で確定した値以外「寸法は推定」の札つき

## 言葉

画面に出す語は5つ（会場図面・階／エリア・品目・並べ方・下敷き）。「シミュレーター」「キャンバス」「レイヤー」「スナップ」「グリッド」「プリセット」「テンプレート」は出さない（`docs/wording.md` ルール6〜9・設計書 §4-1）。
運営マニュアル側の「ブロック」は差し込みブロックの意味でだけ使い、図面に置くものは「品目」。

## 組み上げ方

Claude Design のシード補助で `.dc.html`＋`canvas.json`＋下敷き4枚を1つの html に組み上げて公開する（組み上げた html は `.gitignore`）。
実ブラウザでの確認は `scripts/verify-ui.mjs` と同じ Playwright＋Google Fonts の取り置き（`scripts/lib/google-fonts-cache.mjs`）で行った。

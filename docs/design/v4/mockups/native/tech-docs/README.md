## 言葉

画面の文言は [`../../../../../wording.md`](../../../../../wording.md) のルール5・7・8・9・10・11 に合わせてある（設計書 §4）:

- 見せる語は10: 技術資料／映像パッチ／パッチ番号／機材／増設機材／パッチ盤／技術スタッフ／技術人員／会社／役職
- 出さない語: ジャック・チャンネル・ソース／デスティネーション・FROM／TO・マスタ・DB・データベース。パッチの向きは **送り／受け**、盤の穴は **口**
- 動詞は **追加／編集／削除／キャンセル／保存** ＋ 書き出す・複製する・取り込む・確定する。「探す」は使わず **検索**
- 役職はメンバー表の語をそのまま（SW・CAM・CAM-A・MIX・AUD・CA・CA-A・VE・LD・LD-A・PA・PA MIX・配信管理・3Play・TP・Dv）
- 開発文書の比喩語（道具・決めごと・棚・札・帯・木・種・手つき・作法・入口・出口）は画面に出さない（ルール11）。`node scripts/check-mock-wording.mjs` がこのフォルダを検査する

## 書式

`canvas.json` は Claude Design のキャンバスと同じ形（`v: 3`・`boards`・`order`・`notes`。`native/wiki/canvas.json` と同じ）。
各 `.dc.html` は Claude Design の板（`<x-dc>`・`<sc-for>`・`<sc-if>`・`class Component extends DCLogic`）。

## 組み直し方・確かめ方

- `.dc.html` と `canvas.json` を直したあと、このフォルダを `project/` として同じ URL のキャンバスへ公開し直す
  （Artifact の Design 型。`project/canvas.json` を索引に、各 `.dc.html` を `project/<名前>` で送る）
- 生で開くときは同じ階層に `../../support.js` の複製を置く（`.gitignore`）
- 実ブラウザでの確認は Playwright ＋ Google Fonts の取り置き（`scripts/lib/google-fonts-cache.mjs`）で行った。
  ブラウザは外に出られないので、`support.js` が読む React（`node_modules/react*/umd/*.production.min.js`）と書体を手元から返して描き、
  コンソールのエラー 0・描き残し（`sc-for`／`sc-if` のまま）0・右への はみ出し 0 を見た

## 言葉（2026-09-22 のご指示「UI 上の用語や表現は取り決めどおりを徹底」）

画面の文言は [`../../../../../wording.md`](../../../../../wording.md) のルール5・8・9・10 に合わせてある（設計書 §4-1「動詞と評価の語」）:

- 動詞は既存画面と同じ組: **作成／追加／編集／削除／キャンセル／保存／送信**（＋ 公開する・書き出す・見直す・登録する・却下）
- 評価の3値は制作技術支援の `AiChatSheet.tsx` と同じ **役に立った／言い直して／的外れ**
- 版は画面では **第14版**（`rev` は列名だけ）。技術語（MCP・`body_md`・`pg_trgm`・段）は画面に出さない
- 「探す」は使わず **検索**。「作る／足す／直す／消す／やめる／送る／積む」は使わない

## 色・寸法の出どころ

推測ではなく実装から取った値だけを使っている。

- 色・角丸: `shared/src/client/tokens-v4.css`（`#005bac` `#f7f8fa` `#e6e9ed` `#1a1d24` `#5d6470` `#197a4b` `#c2410e` `#c7243a` `#4338ca` `#6d28d9`）
- 型スケール: `shared/tailwind.preset.ts`（h1 23 / h2 19 / cardtitle 15 / list 13.5 / sub 12.5 / sub-sm 11.5 / badge 11）
- 共通シェル（上辺バー 64・左メニュー 248）: [`../production-manual/Main.dc.html`](../production-manual/Main.dc.html) の写し
- 本文の書体・行送り: ページの本文は 14px / 1.85（読む道具なので一覧の 13.5 より一段大きい）。スマホの本文は 14〜15px・タップ対象は 44px 以上（道具の帯は 48px・主ボタンは 52px）

⚠️ `font-weight` は 400 / 700 / 800 だけ（LINE Seed JP の同梱段）。

## 書式

`canvas.json` は Claude Design のキャンバスと同じ形（`v: 3`・`boards`・`order`・`notes`）。
`docs/design/v4/mockups/native/production-manual/` など先行分の `artboards`／`annotations` 形式とは違う
（キャンバス側の書式が変わったため。中身の役目は同じ）。

## 組み直し方

`.dc.html` と `canvas.json` を直したあと、このフォルダを `project/` として同じ URL のキャンバスへ公開し直す
（Artifact の Design 型。`project/canvas.json` を索引に、各 `.dc.html` を `project/<名前>` で送る）。
生で開くときは同じ階層に `../../support.js` の複製を置く（`.gitignore`）。

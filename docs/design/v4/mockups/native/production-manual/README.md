## 書体とウェイト（2026-09-12 のご指示）

基本は **LINE Seed JP** と **Noto Sans JP**。3つ目の明朝（Noto Serif JP）は題字・引用のとき用。
欧文専用の書体（Roboto Condensed 等）は選択肢に出さない（和欧混植で行がガタつくため。詰めたいときは長体で）。

**ウェイトは、その書体が持っている段を全部出す**（持っていない段は押せるようにしない）。
Google Fonts の CSS を実際に取って確かめた値:

| 書体 | 段 |
|---|---|
| LINE Seed JP | **100 / 400 / 700 / 800**（4段。200・300・500・600・900 は存在しない） |
| Noto Sans JP | **100 〜 900**（9段） |
| Noto Serif JP | 200 〜 900（このモックは 400 / 700 / 900 を読む） |

送りは**プロポーショナル（`palt`）が基本**で、時刻・番号・金額など数字が縦に並ぶところだけ
**等幅（`tnum` ＋ `palt` 0）**。モックの `.num` クラスが実装の `.font-number`
（`tokens-v4.css`）にあたる。

⚠️ **リポジトリに同梱している LINE Seed JP はいま 400/700/800 の3段だけ**
（`scripts/vendor-fonts.mjs` の `CSS_URL`）。100 を足す入れ直しは実装の段A で行う（設計書 §6-5）。
このモックは Google Fonts から 4段とも読んでいる。

## 紙とインクの決めごと（2026-09-12 のご指示）

**出口は紙**なので、紙面（ページの中身）には刷るとインクを食うものを置かない（設計書 §6-6）。

- 地は白。**ベタ塗りの面も、面のグラデーションも置かない**（表紙の濃い面は取りやめた）。
  グラデーションを使ってよいのは**文字の色**だけ（塗る面積が文字の形のぶんだけ）
- 色は**罫・小さなバッジ・文字**にだけ。バッジは塗りつぶさず**枠線**で組む
- 表の見出しは灰色の帯ではなく**上下の罫**。大事な行は塗らずに**左の太罫**で示す（白黒でも分かる）
- 紙面に**影を置かない**。写真は原則載せない（会場図は線画で）
- 罫は 0.25mm 以上。塗り面積の目安は1枚あたり **10% 前後**

⚠️ **これは紙面だけの決めごと。** 画面そのもの（一覧・編集画面の UI）は v4 の共通トークンのまま。

⚠️ **置けないようにはしない**（2026-09-12 のご判断）。上は「既定のひな形と差し込みブロックの作り方」で、
利用者がベタ面や写真を置くのを止めるものではない。代わりに「インクの目安」で知らせるだけ。

`Preview.dc.html` には「インクの目安」（塗り面積・40% で知らせる）と
「色を使わない（白黒で刷る）」を置いてある。

## 長体

`Text.dc.html` の書式パネルで **長体（70〜130%・10%刻み）** と **「1行に収める」** が動く。
1行に収めるは、入り切らないぶんだけ自動で詰める（下限 70%）。

⚠️ **自動の長体は「1回だけ測ってブロックに書き込む」作りにする。** 描くたびに測って
`transform` を書き戻すと固まる（[`../../DESIGN_POLICY.md`](../../DESIGN_POLICY.md)
「測って書き戻す処理を入れない」）。このモックは測っていない（88% の固定値を出しているだけ）。

## 体制図（2026-09-13 追加）

`OrgChart.dc.html` はプロジェクト管理の組織図（`MembersTab.tsx`・migration 169）を
運営マニュアルの**自由ブロック**として作り直す絵。設計の正は
[`../../../production-manual-orgchart.md`](../../../production-manual-orgchart.md)。

- **差し込みブロックにしない。** 番組の冊子には案件が無く、段・箱を持つ表（`gpm_members`）は
  プロジェクト管理からしか編集できないため、差し込みでは制作案件の冊子で永久に空になる
- 立場（自社・発注者・PM会社・業者）は**色ではなく線種**で分ける（白黒で刷っても読める・紙の決めごと）
- 人がまだ決まっていない**空の箱**を紙に出せる（「照明 ── まだ決まっていません」）
- 段のつながりは **CSS の縦罫**。SVG で座標を計算しない（箱の高さは人数で変わる。GPM が実測で学んだこと）

サンプルの管理番号は改番後の **`SCS-0007`**（[`../../../../reorg-2026-10-plan.md`](../../../../../reorg-2026-10-plan.md)）。
ほかの絵はまだ改番前の `GLS-A002` のままなので、組み直すときにそろえる。

# ONAiR とは

社内で使うシステムの名前がすべて「ONAiR」なので、まず「ひとつの機能の名前ではなく、いくつものアプリをまとめた土台の名前」だと知っておくと、目的のアプリに迷わずたどり着けます。

## ONAiR は何の名前か

- ONAiR は、GMOグローバルスタジオの仕事の進み方（案件・お金・予定・機材など）をまとめて管理する仕組み全体の名前です。
- 「ONAiRを開く」といっても、実際には目的に応じていくつかのアプリを行き来する形になります。
- 会社の仕事の流れを支える土台なので、社内では「会社OS」と呼ぶこともあります。

## すべてのアプリをつなぐ「GLS番号」

- 案件（仕事の依頼）が受注（正式に決まること）になると、自動でつく番号です。
- 見積・売上・仕入・機材の貸し出しなど、その案件に関するあらゆる情報が、このGLS番号を通じてひとつにつながっています。
- 番号そのものを意識して入力する場面はほとんどありません。裏側で案件を束ねている仕組みだと知っていれば十分です。

## いま使えるアプリ

### 案件管理・財務管理・カレンダー・設定
案件（仕事の依頼）に関わる人が使う、いちばん中心になるアプリです。見積・売上・仕入・利益の状況・スタジオや人の予定・権限設定などをまとめて扱います。案件化を伴わない仕事を扱う「プロジェクト管理」もこのアプリの中にあります。

### 日常業務
社内の連絡や届き物を扱う人が使います。週報・社内ニュース・内覧会の予定・届いた書類の受け取り・入館証（セキュリティカード）の管理などができます。

### 機材管理
スタジオの機材を扱う人が使います。機材の台帳・ラックの配置図・貸し出しの記録・棚卸し（在庫の確認）ができます。

### 制作技術支援
番組や収録の進行を担当する制作スタッフが使います。台本づくり・本番の進行表・プロンプター（出演者向けの原稿表示）・音声のサポートなど、収録・配信の現場を支えます。

### 計時・視聴者
本番中の時間管理と視聴者数の表示を担当する人が使います。制作技術支援と組み合わせて、放送中の画面に出す情報を扱う小さなアプリです。

## 使われなくなった機能

放送演出用の「リアルタイムCG」というアプリは、配信としては使われなくなりました。中身のデータや仕組みは残してありますが、いまの業務で使う場面はありません。

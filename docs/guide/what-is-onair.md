# ONAiR とは

「ONAiR」は1つの機能の名前ではありません。**いくつものアプリをまとめた土台の名前**です。
これを知っておくと、目的のアプリに迷わずたどり着けます。

## ONAiR は何の名前か

- GMO ONAiR は、GMOグローバルスタジオの仕事（案件・お金・予定・機材・本番の進行）を
  まとめて管理する仕組み**全体**の名前です。社内では「会社OS」とも呼びます。
- 中身は、役割ごとに分かれた小さなアプリ（**ブロックアプリ**）の集まりです。
  「ONAiR を開く」＝トップページでアプリを選ぶ、という形になります。
- ログインは1回で済みます。アプリを行き来しても入り直す必要はありません。
- トップページに出るタイル（アプリの入口）は、**その人に権限があるものだけ**です。
  見えないアプリがあるときは、壊れたのではなく権限が付いていません（権限は管理者が設定で変えます）。

## すべてのアプリをつなぐ番号「管理番号」

- 案件1件ごとに付く番号です。画面では**「管理番号」**と表示します（2026-09-08 に呼び名を統一しました）。
- 番号そのものは `GLS-A012` のような形なので、**「GLS番号」と呼ぶ人もいます。同じものです。**
  `A` は案件（撮影・収録・配信・イベント）、`B` はプロジェクト（工事・構築）を表します。
- 案件を作った時点では付きません。ステージが「D 仮押さえ」以降なら手で採れ、
  「A 受注済」に進むと自動で採ります。
- この番号を通じて、見積・売上・仕入・請求・回（実施の単位）のコード・BOX のフォルダ名・
  カレンダーの予定名・進行台本（制作技術支援）・機材の設定が1つにつながります。
  どのアプリで作業していても、管理番号を見れば同じ案件だと分かります。
- **2026年10月の事業再編**（社名変更・売上を計上する会社が2社になる）で、新しい番号
  `SCS-0001` / `GSS-0001` / `GMO-0001` に切り替える設計が進んでいます。
  切り替えても**いまの番号は消えず、旧番号のまま検索できる**設計です。
  切替の日取りや細かい運用は**決まり次第**この説明書に書きます。今日の時点では何も変わっていません
  （[用語集の「計上会社」](words.md#計上会社)）。

## いま使えるアプリ

トップページに並ぶ順です。「一言」は画面のタイルに出ている説明文そのものです。

| アプリ | 一言（タイルの説明） | 何をするところか | 入口 |
| --- | --- | --- | --- |
| ホーム | アプリを選ぶ | トップページ。今日の予定・自分の仕事・アプリのタイル | `/` |
| 案件管理 | 案件パイプライン・顧客・見積 | 撮影・収録・配信・イベントの仕事を、受付から受注・実施・ふりかえりまで追う。取引先・見積・案件台帳もここ | `/sales` |
| プロジェクト管理 | 自社構築・グループ受託の工程管理 | スタジオや設備を作る・更新する「工事・構築」の仕事を工程表で追う。案件管理と対になる | `/gpm` |
| 制作技術支援 | 台本・スケジュール・収録配信・本番送出 | 番組・イベントを1つ選ぶと、その中の道具（ミニアプリ）に分かれる（下の表） | `/techops` |
| 財務管理 | 売上・仕入・販管費・損益 | 売上・仕入・販管費・損益・請求と入金・月次の締め | `/budget` |
| カレンダー | スタジオカレンダー・ブッキング | スタジオ（部屋）の予約と、人の予定 | `/calendar` |
| 日常業務 | 週報・ニュース・内覧会・受領書類 | 週報・社内ニュース・内覧会・届いた書類・セキュリティカード（入館証）の貸出 | `/daily` |
| 機材管理 | 機材台帳・貸出・メンテナンス | 機材の台帳・ラック図・貸出・棚卸し | `/equipment` |
| 設定 | 権限・ユーザー・データ・バックアップ | 利用者と権限・取引先マスター・料金表・データとバックアップ・10月の再編の下準備「会社と切替」 | `/settings` |

- 案件管理・プロジェクト管理・財務管理・カレンダー・設定は、権限としては**1つのまとまり**です。
  案件管理の権限があれば、この5つの入口が見えます（中の画面ごとに「見るだけ」「直せる」の段階はあります）。
- 旧「受付」（`/sales/inbox`）は案件作成に畳みました。古いリンクを開いても案件作成に転送されます。

### 制作技術支援の中の道具（ミニアプリ）

制作技術支援は「まず番組・イベントを選ぶ → その中の道具を開く」という順番です。

| ミニアプリ | 何をするか |
| --- | --- |
| 進行台本 | 本番の進行表（通称 Qシート）を作る・配る。本番中の進行・ランダウン・プロンプター・音声サポートの画面もここから |
| スケジュール表 | 当日の進み方を時間で並べた表（香盤表） |
| 収録設定 ／ 配信設定 | 収録・配信の機材の設定を、案件ごとに1セット持つ |
| レンタル機材検索 | 借りる機材を探して見積を依頼する |
| 計時・視聴者 | 本番の残り時間と同時視聴者数を大画面に出す |
| テロップCG | 本番中に画面へ出す文字・CG を送出する（旧「リアルタイムCG」の後継） |

- **計時・視聴者はアプリ一覧に出ません。** 制作技術支援で番組を選び、そこから開きます。
  大画面に出す表示画面（`/live/display/…`）は、ログインなしで開ける公開URLです（配信ソフトから読み込むため）。
- 本番中に使う画面（進行・ランダウン・プロンプター・音声サポート・テロップCG の出力）は、
  見た目を変えない約束で動いています。急に変わることはありません。

## 使われなくなった機能・名前が変わったもの

**リアルタイムCG は廃止しました（2026-09-06）。** 後継は制作技術支援の中の「テロップCG」です。
URL を直接入力しても開けません。過去の実績データは消しておらず、テロップCG 側の移行ツール
（設定 ＞ 連携 ＞ 過去実績の移行。システム管理者だけ）が読みます。

名前が変わったものは、古い呼び名で覚えている人も多いので対応表を置きます。

| 以前の呼び名 | いまの呼び名 | いつ・補足 |
| --- | --- | --- |
| 制作資料 | 制作技術支援 | 2026-08-22。トップページで案件管理側の並びに格上げ |
| Qシート（アプリ名として） | 進行台本（制作技術支援のミニアプリ） | 「Qシート」は通称として今も使ってよい。旧URL `/qsheet/…` は新URLに転送される |
| 計時LIVE | 計時・視聴者 | 2026-08-22。制作技術支援の中から開く |
| リアルタイムCG | テロップCG（制作技術支援のミニアプリ） | 2026-09-06 に旧アプリは廃止 |
| スタジオ案件 ／ ビジネス案件 | 案件 ／ プロジェクト | プロジェクトはプロジェクト管理アプリへ |
| GLS番号 | 管理番号 | 2026-09-08。画面の表示だけ。番号の形（`GLS-A012`）は同じ |
| 受付 | 案件作成 | 案件作成に統合。旧URL は転送される |

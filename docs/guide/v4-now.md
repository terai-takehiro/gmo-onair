# v4 って何？ 今どこまで進んだ？

GMO ONAiR の画面は、今この瞬間も新しい見た目に作り直されています。この作り直しの取り組みをまとめて「v4」と呼びます。急に画面のデザインが変わっていても壊れたわけではないので、まずこれを読んで背景を知ってください。

## v4 とは何の取り組みか

v4 とは、ONAiR の画面の見た目と使い勝手を、まとめて新しく作り直す取り組みの名前です。

機能を1つ増やすような話ではありません。案件管理・財務管理・カレンダー・設定・日常業務・機材管理など、いろいろな画面をまたいで、次のようなことを揃え直しています。

- 文字や金額の並び方
- 色や文字の大きさ
- スマートフォンでの操作しやすさ
- 画面に出てくる言葉づかい

## なぜやっているか

これまでの ONAiR は、機能を足すたびに少しずつ画面を継ぎ足してきました。その結果、画面ごとに見た目や言葉づかいがバラバラになり、分かりにくいところや、実は使われていない機能も残っていました。

v4 は、それを一度きちんと整理し直すための取り組みです。目的は主に3つです。

- **使いやすさ**: どの画面でも同じ操作感にする
- **スマートフォン対応**: パソコンだけでなく、スマートフォンでも快適に使えるようにする
- **見た目の統一**: 画面ごとにバラバラだった色・文字・並び方を揃える

## どのくらい進んでいるか

進み具合は画面の数によって日々変わるので、ここには具体的な数字を書きません。

**今どの画面が新しくなっていて、どの画面がまだかを画面ごとに確認したいときは、[v4-progress.md](../v4-progress.md)（進み具合が分かるページ）を見てください。** このページは自動で作り直されるしくみになっているので、常に実際の状態と一致しています。

## まだ終わっていません

v4 はまだ作業の途中です。新しくなっていない画面も残っていますが、見た目が変わっていないだけで、いつも通り使えます。

残りの作業は、今後も通常の開発の一部として少しずつ続いていきます。急いで全部を一度に終わらせるものではないので、気長に見守ってください。

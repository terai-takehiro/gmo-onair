# v4 って何？ 今どこまで進んだ？

ONAiR の画面は、いまも新しい見た目に作り直されています。この作り直しの取り組みをまとめて「v4」と呼びます。
急に画面のデザインが変わっていても壊れたわけではないので、まず背景を知ってください。

## v4 とは何の取り組みか

- 2026年8月に本番に出た v4 系の版（`v4.0.0` から始まる番号）で始まった、
  **画面の見た目と使い勝手をまとめて作り直す取り組み**です。いまの版 v4.6.10 も同じ取り組みの続きです。
- 機能を1つ足す話ではありません。次の5つを、対象の画面すべてに同じルールで効かせています。
  1. 縦の整列（数字や項目の並び）
  2. 金額の表記
  3. スマートフォンでの手触り
  4. 言葉づかい
  5. ページの外枠（上のバー・左のメニュー・スマホの下タブ）
- **設計図は「モック」**（`docs/design/v4/mockups/`）で、v4 ではモックが正です。
  実装や過去の決めごとがモックと食い違ったら、モックに合わせます（[用語集の「モック」](words.md#モック)）。

## なぜやっているか

v3 までの ONAiR は、機能を足すたびに画面を継ぎ足してきました。
その結果、画面ごとに見た目や言葉づかいがバラバラになり、分かりにくいところや、実は使われていない機能が残っていました。
v4 は、それを一度きちんと整理し直すための版です。

## どのくらい進んでいるか

進み具合は画面の数で日々変わるので、ここには数字を書きません。

**[docs/v4-progress.md](../v4-progress.md)（進み具合のページ）を見てください。**
このページは、画面のプログラムを機械が読んで自動で作り直すしくみなので、実際の状態と一致します。

| 印 | 意味 |
| --- | --- |
| ✅ | v4 で作り直した |
| ⬜ | まだ（見た目は今までのまま・動きます） |
| ⏸ | 意図して据え置き（そのページの注記を読む） |
| 🆕 | これから新しく作る（いま画面がない） |

- 数えているのは、案件管理・財務管理・カレンダー・設定・共通の画面・日常業務・機材管理・プロジェクト管理です。
- **制作技術支援は別に進めています。** 外枠と共通部品は v4 に載せ替え済みで、
  進行台本の表本体と本番中に使う画面はまだです（本番中の画面は、見た目を変えない約束で動いています）。
  残りの段取りは [docs/reviews/techops-ui-unification-plan.md](../reviews/techops-ui-unification-plan.md)（エンジニア向け）。
- ⚠️ 要確認: 進み具合のページの末尾「凍結」の欄は、古い名前（制作資料・技術資料・計時LIVE・リアルタイムCG）のまま
  4つ並んでいます。いま凍結のアプリは0で、リアルタイムCGは廃止、技術資料はアプリごと無くなっています（v4.2.0）。
  ページを作る仕組み（`scripts/v4-progress.mjs`）のほうを直す必要があります。

## v4 のあとに始まった取り組み

v4 の作り直しに加えて、2026年8月から次の取り組みが動いています。

- **全画面をパソコン・スマホのアプリ級にする**（2026-08-20〜）: 「PC専用」を原則やめ、
  すべての画面をスマホでも使えるようにする追加の取り組みです（[docs/v4-native-ui-plan.md](../v4-native-ui-plan.md)）。
- **制作技術支援の作り直しの続き**: 上の「別に進めています」の残り。2026-09-08 からは、
  ページの幅や見出しの大きさなど画面ごとにばらついていた作りを揃える段に入っています。
- **テロップCG**（2026-09-06）: リアルタイムCGの後継として制作技術支援の中に作り、旧アプリは廃止しました。
- **10月の事業再編の下準備**: 設定 ＞ 会社と切替（[用語集の「計上会社」](words.md#計上会社)）。

## まだ終わっていません

- ⬜ の画面も、色・書体・上下のバーのような土台は v4 のものが効いています。
  「まだ」なのは、その画面の中身（並べ方・列・見出し）だけです。
- 新しくなっていない画面も、見た目が変わっていないだけでいつも通り使えます。
- 残りの作業は、通常の開発の一部として続きます。急いで全部を一度に終わらせるものではありません。

# 本番と検証・壊していい場所

間違えて実際の会社のデータを壊さないために、いま自分がどちらの環境を見ているかを先に確認しましょう。

## 2つの環境は別物

GMO ONAiR には「本番」と「検証」という、完全に別々の入れ物が2つあります。

- **本番**（`gmo-onair.jp`）: 実際の会社のデータが入っている場所です。
- **検証**（`dev.gmo-onair.jp`）: 確認や練習のための場所です。

この2つはデータベース（情報をためておく場所）も別々です。本番のデータが検証に流れ込むことはありませんし、その逆もありません。

## 検証は自由に触ってよい

検証環境にはダミーデータ（練習用に用意した架空のデータ）が入っています。

- 触って壊れても問題ありません。
- 新しい機能を試したいときはここを使います。
- 数日ごとに検証環境の中身が入れ替わることもあります。

## 本番は慎重に扱う

本番環境には実際の会社のデータが入っています。

- 実在するお客様や案件の情報がそのまま反映されます。
- むやみに操作したり、練習のつもりで触ったりしないでください。
- 本番に新しい変更を反映してよいかどうかは、会社として判断してから決めます。担当者から案内があるまでは待ちましょう。

## どちらを見ているか分からないとき

**URL（アドレスバーに出ている文字列）のドメイン（`gmo-onair.jp` か `dev.gmo-onair.jp` か）で見分けられます。** 何か操作する前に、アドレスバーを確認する癖をつけると安心です。

## ログイン方法も違う

環境によってログインのしかたも変わります。

- **検証**: 画面に並んだ人のカードから自分を選ぶだけでログインできます。
- **本番**: メールアドレスとパスワードに加えて、SMS（携帯電話に届く確認コード）での本人確認も必要です。

ログイン画面の見た目が普段と違うと感じたら、まずどちらの環境を開いているかを確認してみてください。

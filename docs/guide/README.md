# だれでも読める説明書

GMO ONAiR を使う**社内の人**（エンジニアでない人）のための説明書です。
ボタンの押し方のような操作の説明は、画面右上の本人メニューにある「利用マニュアル」にあります。
ここにあるのは、その手前の「そもそも何なのか」「どこを見ればよいか」です。

- 2026-09-08 時点（版は v4.6.10）の事実に合わせて書き直しました。
- 画面や決めごとが変わったら、この6本も直します。エンジニア向けの文書一式は
  [docs/README.md](../README.md) にあります。
- 分からないこと・人の判断が要ることは、本文に「⚠️ 要確認」と残してあります。

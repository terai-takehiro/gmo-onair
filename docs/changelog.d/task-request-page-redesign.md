**「タスク・依頼」（`/daily/tasks`）をモックから設計し直した**（設計の正は [docs/design/v4/mockups/tasks-redesign/](../design/v4/mockups/tasks-redesign/)）。①**依頼タブから依頼を出せるようにした** — この画面は受けた／出した依頼を読むだけで、依頼を作る操作が1つも無く、手で1件出す唯一の道はマイタスクの「追加」で担当者を自分以外に変えること（選ぶまでそれが依頼になると分からない）だった。投入口を AI（案件管理トップの入力欄・要件 D4）に寄せた結果、手で出す動線が画面から消えていた。主操作をタブごとに変え、依頼タブは「依頼する」（相手 → 内容 → 補足 → 期限 → 重要度・緊急度の順・期限必須）にした。②**一覧と詳細を分けた** — 1件が縦長カードで全行にコメント欄の折りたたみが付いており、5件並ぶと画面が操作ボタンで埋まってどれが自分の番か読めなかった。一覧は1行（状態96px／内容／期限128px）に揃え、本文・やり取り・操作は選んだ1件のパネル（スマホはシート）にだけ出す。③**「あなたの番」を先頭に出した**（受けたのに返していない ＋ 出したが差し戻されて決めていない）。タブの見出しにも同じ件数を出す。④**状態で絞り込めるようにした**（すべて／未返答／承諾／差し戻し／完了・件数つき）。以前は「対応済の依頼も表示」のトグル1つだけだった。⑤**承諾した依頼をこのタブで対応済にできるようにした**（以前はマイタスクへ移らないと片づけられなかった）。⑥マイタスクも絞り込みを件数つきのチップ（すべて／期限超過／本日／期限未設定／完了）にし、一覧を `Row` に載せ、警告帯2本を1本に畳んだ。チームは行から「依頼する」を開けるようにした。⑦**ページ幅を他の画面に合わせた** — `mx-auto max-w-5xl p-4 sm:p-6` はこのアプリでこの画面だけで、他11画面はすべて全幅だった。⑧`violet` / `amber` / `sky` / `rose` / `slate` の直書きと `text-[10px]` 等の直書きをやめ、状態トークン・型スケールにそろえた。要件（4タブ・9マス・今日やること3件・期限必須）は変えていない。検証: `npx tsc -b client client-daily server`・`npm run lint`・`npm run test` 通過。

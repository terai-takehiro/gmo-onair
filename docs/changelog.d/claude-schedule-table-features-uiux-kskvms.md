**制作技術支援＞スケジュール表で、列を画面から作れる・直せるようにし、空の表に「最初の一手」を出した**（9/6 ご依頼「現状 MCP くらいしかできる機能がなく、根本的な機能性が皆無」・第2版計画の PR1）。①⚠️ **新しく作った表は列が 0 本で、列を作る画面が無かったため、ひな形か AI を通す以外に何もできなかった**（「項目を追加」も押せない）。サーバー・MCP には列の追加・改名・並べ替え・削除が前からあり、画面に配線されていないだけだった。列が 0 本のときは「ひな形から／会場を選んで列を作る／AI で下書き」の 3 択を出し、「会場を選んで列を作る」はスタジオの部屋を複数選ぶと 1 部屋 1 列で会場列を作る（部屋の色を列の色に引き継ぎ、拠点が未設定なら表の拠点も埋める）。②列見出しの鉛筆から名前・部屋・色を直し、左へ／右へで並べ替え、削除（項目数を書いた確認つき）ができるようにした。列の色は見出しの丸と項目の左罫に出る。③見出しの 4 ボタン（ひな形・AI・Excel・項目）を「項目を追加」＋「…」（列を足す／ひな形を適用／AI で下書き／Excel）に整理し、`PageHeader` に載せたのでスマホでは「項目を追加」が下端に出る（これまでスマホから項目を足せなかった）。④項目の削除の確認を `window.confirm` から共通の `confirmAction` に替えた。部屋の一覧は `GET /techops/studio-rooms`（読み取りのみ）を新設して読む——カレンダー側の `/studios/locations` は営業権限の下にあり技術・運営のアカウントでは 403 になるため。

**続けて PR2 として、表そのものの編集・削除・共有ができるようにした。** ⑤表の設定シート（題・日付・拠点・案件/番組・回・表示時間帯・状態・備考）と削除を新設した——`PUT/DELETE /schedules/:id` は前からあったが、画面からの呼び出し元が1つも無く、題や日付を直す・状態を「確定」にする・表を削除する、が全部できなかった。見出しに状態バッジ（下書き／確定／保管）も出るようにした。⑥**案件メンバーには自動で共有する**（9/6 ご判断）。共有テーブルに写さず、`canAccessSchedule`・一覧の可視条件で `project_members`・案件の主担当を動的に見る形にしたので、メンバーの増減にそのまま追随する（マイグレーション不要）。番組はメンバー概念が無いので従来どおり明示共有のみ、進行台本の共有は変えていない。設定シートの「共有」節に「案件 GLS-xxxx のメンバー N 人には自動で見えます」と事実だけ出し、それ以外に見せたい人はユーザー検索から足す（`GET/PUT /schedules/:id/shares`。作成者・管理者のみ操作可）。⑦**実装中に見つけた既存バグも同時に直した** — `PUT /schedules/:id`（REST・MCP `update_schedule` 双方）は `キー: 条件 ? 値 : undefined` という組み立て方をしており、`updateSchedule` 側の「送られたか」判定（`'projectId' in input`）が**値が undefined でも常に true になる**ため、拠点・案件・番組・回・備考を**指定しなかっただけで毎回 null に戻す**状態だった。この経路はこの PR まで呼び出し元が無く誰も踏んでいなかった。スプレッド構文に直し、実 DB で「一部だけ更新しても他のフィールドが消えない」ことを確認した。

**続けて PR3 として、新規作成の入力欄・スマホの列絞り込み連携・ひな形設定への導線を整えた（サーバー変更なし）。** ⑧新規作成ダイアログに拠点・案件/番組・回・ひな形・本番開始時刻を足した。案件を選ぶと題（案件名）・日付（本番日の初日）を空欄のときだけ先埋めする——拠点は案件の事実に id が含まれない（部屋名の文字列のみ）ため先埋めしない。一覧の絞り込みから来た新規作成は、これまでどおり案件/番組を選び直させない。「案件／番組」の選び方は表の設定シートと共通の部品（`ScheduleOwnerFields`）にまとめた。⑨スマホの列チップの絞り込みを画面の見出しまで持ち上げ、「項目を追加」が絞り込み中の列を既定にするようにした——以前は絞り込んでいても常に先頭の列に追加していた。⑩「スケジュール表のひな形」への導線を左メニュー（`system_admin` のみ）とひな形適用ダイアログ（「ひな形を直す」リンク）に足した——これまで URL 直打ちでしか開けなかった。⑪ひな形の項目に区分・基準（当日00:00から／本番開始から）・オフセット・尺・必須を追加し、追加だけでなく編集もできるようにした（これまでは消して作り直すしかなかった）。ひな形の名前・説明・拠点の変更と複製ボタンも追加した。列の名前・部屋・色の変更は今回もできない（サーバーに対応する更新 API が無いため。画面には「消して作り直してください」と書いた）。

**制作技術支援＞スケジュール表で、列を画面から作れる・直せるようにし、空の表に「最初の一手」を出した**（9/6 ご依頼「現状 MCP くらいしかできる機能がなく、根本的な機能性が皆無」・第2版計画の PR1）。①⚠️ **新しく作った表は列が 0 本で、列を作る画面が無かったため、ひな形か AI を通す以外に何もできなかった**（「項目を追加」も押せない）。サーバー・MCP には列の追加・改名・並べ替え・削除が前からあり、画面に配線されていないだけだった。列が 0 本のときは「ひな形から／会場を選んで列を作る／AI で下書き」の 3 択を出し、「会場を選んで列を作る」はスタジオの部屋を複数選ぶと 1 部屋 1 列で会場列を作る（部屋の色を列の色に引き継ぎ、拠点が未設定なら表の拠点も埋める）。②列見出しの鉛筆から名前・部屋・色を直し、左へ／右へで並べ替え、削除（項目数を書いた確認つき）ができるようにした。列の色は見出しの丸と項目の左罫に出る。③見出しの 4 ボタン（ひな形・AI・Excel・項目）を「項目を追加」＋「…」（列を足す／ひな形を適用／AI で下書き／Excel）に整理し、`PageHeader` に載せたのでスマホでは「項目を追加」が下端に出る（これまでスマホから項目を足せなかった）。④項目の削除の確認を `window.confirm` から共通の `confirmAction` に替えた。部屋の一覧は `GET /techops/studio-rooms`（読み取りのみ）を新設して読む——カレンダー側の `/studios/locations` は営業権限の下にあり技術・運営のアカウントでは 403 になるため。あわせて第2版計画（[docs/design/v4/qsheet-v4-coding/14-schedule-v2-plan.md](docs/design/v4/qsheet-v4-coding/14-schedule-v2-plan.md)）と利用者の判断 2 件（1 日 1 枚のままイベントごとにまとめる／案件メンバーへ自動共有）を記録した。検証: `server`/`client-techops` の型チェック、ESLint、UI トークン検査、`shared` の Vitest 1996 件、実ブラウザ（Playwright・PC 1280 と 375px）で空状態→列作成→並べ替え→削除まで通し、横はみ出し 0px・JS エラー 0 件。

**制作技術支援の番組・イベント一覧を「いつやるか」で組み直し、案件台帳の絞り込みに新番号を足した**。

## 修正

- **制作技術支援トップ（`/techops/top`）に、番組・イベントではない案件が混ざっていたのをやめた。**
  工事・構築のプロジェクト（旧 `GLS-B###`・改番後の `GMO-####`。「第3本社プロジェクト」
  「渋谷スタジオプロジェクト」など）と失注案件を、サーバー側（`top.routes.ts`）で外した。
  分類が未設定の古い案件は GLS-A 扱い（「案件を編集」・`missingOf` と同じ基準）
- **行に本番日（イベント・放送の日）を必ず出すようにした。** 以前は日付を1つも出しておらず、
  並びは放送順なのに「なぜこの順なのか・いつやるのか」が画面から読めなかった。
  これからの本番は日付＋残り日数（今日／明日／あと8日）、複数日イベントの途中は「開催中」、
  日付を持たないものは「日程未定」とはっきり書く
- **並びを放送順（本番日の昇順）に統一した。** 同じ日は名前順（引くたびに入れ替わって見えないように）。
  日程未定のものだけ最後にまとめる
- **日付が過ぎたものが本体の一覧に残り続けていたのを直した。** 以前は `last_date` が無い案件を
  「終了しない扱い」にしていたため、実施日を入れないまま完了した案件が永久に残っていた。
  日付を持たない案件は**ステージ**で判断し、実施済・完了ならアーカイブへ畳む
  （日付が無いだけでまだ動いている案件はそのまま残す）
- あわせて `projects.event_start` / `event_end`（TEXT）の空文字をサーバーで `NULL` に落とした
  （空文字がそのまま日付として渡ると、クライアントの日付計算が Invalid Date で落ちる）
- **案件台帳の分類プルダウンに、新しい発番（`SCS-` / `GSS-` / `GMO-`）を先頭に足した。**
  「新番号（SCS・GSS・GMO）」＋会社ごとの3つを上に置き、旧 `GLS-A` / `GLS-B` /
  旧GLS（決算取込）はその下に残した。**計上会社の絞り込みとは別の軸**（既存行の
  `entity_code` はすべて `GSS` に埋まっているので、「GSS の帳簿の案件」と「`GSS-` で始まる
  番号の案件」は一致しない）。番号の接頭辞は `legal_entities.number_prefix` を正とし、
  サーバー（`GET /projects?number_series=`）で絞る

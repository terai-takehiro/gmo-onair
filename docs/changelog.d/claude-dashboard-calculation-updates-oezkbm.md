**財務ダッシュボードの損益の流れとグループ内外カードの表示を見直した**。①損益の流れ（`/budget/dashboard`）は、見出し（大きいカード）が限界利益／売上総利益／営業利益、材料（下の小さい行）が売上／仕入（変動原価）／固定原価／販管費という並びだった。「見出しは売上／仕入（変動原価）／粗利／営業利益、材料は固定原価／販管費にしてほしい」というご要望に応え、見出しを4枚（売上・仕入（変動原価）・粗利〈旧・売上総利益〉・営業利益）、材料を2行（固定原価・販管費）に組み替えた。限界利益は途中の値のためどちらにも出さない（案件で絞り込み中の3枚だけの表示は変更なし）。②「グループ内／グループ外」カードは売上・仕入しか出しておらず、絞り込み状態での粗利がグループ内外で分からなかった。ご要望に応え、各カードに粗利（売上－仕入。固定原価は特定のお客様に紐づかないため対象外＝限界利益と同じ式）を追加した。値はサーバー（`monthly-summary.service.ts`）が出したものをそのまま表示し、画面側では計算し直さない。検証: `npx tsc -b client`・`npx tsc -b server`・`npm run lint`・`npm test`。

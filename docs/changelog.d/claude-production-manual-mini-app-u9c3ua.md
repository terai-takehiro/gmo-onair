**運営マニュアルの書体・ウェイト・送りの決めごとを足し、モックの取りこぼしを直した**（設計 §6-5）。①ご指示に沿って「書体は LINE Seed JP と Noto Sans JP が基本／ウェイトは全部使えるように／送りはプロポーショナルが基本で、デザイン上そうしたいところは等幅」を設計に落とした。ウェイトは**その書体が実際に持っている段だけを出す**（押しても変わらない欄を作らない・ブラウザが合成した偽の太字を紙に出さない）とし、Google Fonts の CSS を実際に取って段を確かめた——LINE Seed JP は 100/400/700/800 の4段（200・300・500・600・900 は存在しない）、Noto Sans JP は 100〜900 の9段。書体を変えたときはいちばん近い段へ自動で寄せる。欧文専用の書体（Roboto Condensed 等）は和欧混植で行がガタつくため選択肢に出さず、詰めたいときは長体（`transform: scaleX()`）で行う。送りは既定が `palt`（`base.css` の `body` と同じ値）で、時刻・番号・金額など数字が縦に並ぶところだけ `palt 0` ＋ `tnum 1`（`tokens-v4.css` の `.font-number` と同じ値）。**同梱の LINE Seed JP はいま 400/700/800 の3段しか入れていない**ため（`scripts/vendor-fonts.mjs` の `CSS_URL`）、段A の前に `wght@100;400;700;800` へ直して入れ直すことと、`client-techops/index.html` の Noto Sans JP に `100;200` を足すことを作る順に書き込んだ。②あわせてモック8枚を機械的に見直し、見つけた不具合を直した——差し込みカタログで16項目中14項目が右パネルに別の項目（体制・連絡先）を出していた（「WEB会議」では伏せ字の警告そのものが出なかった）、ページのサムネを押しても何も変わらなかった、ひな形のブロック（柱）が自由ブロックの枝に流れていた、スマホでページをめくると別のページの題が出た、`<button>` の中に `<div>` があった、表紙のサムネ・差し込みカタログ・考え方の地図・A4横の実寸ページで中身が枠からはみ出していた、冊子番号とページ番号と時刻が画面ごとに食い違っていた、英語が1か所紛れていた。検証: `node scripts/check-md-links.mjs`・`node scripts/check-changelog.mjs`・モック8枚の構文とキャンバス定義の機械検査。

**運営マニュアルを「紙に刷る前提」で組み直し、長体と『1行に収める』を足した**（設計 §6-5-1・§6-6）。①ご指示「印刷が基本であることを意識し、インクを大量に使用するようなデザインは回避したい」に応え、紙面の設計規律を決めた——地は白でベタ塗りの面を置かない／面にグラデーションを使わない（文字の色に使うのは可・塗る面積が文字の形のぶんだけ）／色は罫・小さなバッジ・文字にだけ使う／バッジは塗りつぶさず枠線で組む／表の見出しは灰色の帯ではなく上下の罫／大事な行は塗らずに左の太罫で示す（白黒でも分かる）／紙面に影を置かない／写真は原則載せず会場図は線画で／白黒で読めること／罫は 0.25mm 以上。塗り面積の目安は1枚あたり 10% 前後。モックもこれに合わせて直し、表紙が A4横の 44% を濃いグラデーションで埋めていたのを白地＋細い罫に、表の見出しの灰色の帯を上下の罫に、大事な行のベタ塗りを左の太罫に、QR の黒地を白地に変えた。⚠️ これは**紙面（ページの中身）だけ**の決めごとで、画面そのもの（一覧・編集画面の UI）は v4 の共通トークンのままにしてある。書き出しの画面には「インクの目安」（塗り面積・40% を超えたら知らせる）と「色を使わない（白黒で刷る）」を置いた。②ご指示「長体が使えるようにして欲しい（1行に収めたい時があるので）」に応え、長体（70〜130%・10%刻み・`transform: scaleX()`）に加えて**「1行に収める」**を足した。入り切らないぶんだけ自動で詰め、下限 70%、それでも入らなければ詰めるのをやめて省略記号にする。⚠️ 自動の長体は**1回だけ測ってブロックに `style.scaleX` として書き込み、描くときは測らない**作りにすることを設計に明記した——`docs/design/v4/mockups/DESIGN_POLICY.md` の「測って書き戻す処理を入れない」は、v4 のモックで同じ長体フィットを入れて再測定と再描画が連鎖し画面が固まった実績に基づくため。検証: `node scripts/check-md-links.mjs`・`node scripts/check-changelog.mjs`・モック8枚の構文とキャンバス定義の機械検査。

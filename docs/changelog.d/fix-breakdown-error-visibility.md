**財務ダッシュボードの内訳が読めなかったとき、「0件」と嘘をつかないようにした**（棚卸し ⑥）。⚠️ **これまでは内訳が 504 で落ちても「この期間の確定売上はありません。」としか出ていませんでした** — 合計だけがエラー表示に繋がっており、内訳3列は失敗しても空に落ちるだけだったため、**見ている人は「本当に無い」と受け取ります**。しかも既定では 5xx を2回リトライするので、**その嘘が最大3回ぶんの待ち時間ずっと表示され続けて**いました。件数を「数えられなかった」と言える形（`—件`）にし、失敗した列にだけ断りと「この内訳をもう一度読み込む」を出す。⚠️ **列ごとエラー表示に差し替えてはいません** — 見出しの合計金額は別の集計から来ていて**成功している**ので、差し替えると正しい数字まで消えます。⚠️ **仕入の列は変動原価と固定原価の2本を足している**ので、片方だけ落ちたときに足し算のままだと「失敗を出したのに件数だけ嘘」になる。どちらか落ちたら件数を出さず、固定原価だけ落ちた場合は行を出したうえで「固定原価を読み込めませんでした。下の一覧はそれを除いた分です。」と断る。⚠️ **読み上げは `alert` ではなく `status`**（3列同時に落ちると読み上げが3連発で割り込むため。全面のエラー表示が既に `alert` を持っている）。あわせて内訳のリトライを1回に落とした（補助情報なので早く失敗を見せる。合計は元から1回）。検証: 実ブラウザで**売上の内訳だけを 504 にして**、「—件」＋断り＋読み直しボタンが出ること、**嘘の「確定売上はありません」が出ないこと**、隣の仕入・販管費は普通の「0件」のままで見分けが付くこと、合計は成功しているので全面のエラーは出ないことを確認。

**検収書PDFの日付を発行日にし、トップページ「日常業務」フライアウトの漏れを直した**。
①案件管理から検収書としてPDFを発行すると、右上の日付が過去の日付（請求日・計上日）に
なっていた。検収書は「発行した日」を表す書類なのに、見積書・請求書と共通の日付算出ロジック
（請求日→計上日→今日、の優先順）をそのまま使っていたため。`pdf.service.ts` で検収書のときだけ
常に発行時点の日付を出すようにした。
②トップページの「日常業務」タイルにマウスを合わせたときのフライアウトメニューに、
新設済みの「フィードバックチケット」「タスク・依頼」が出ていなかった（`AppTiles.tsx` の
ハードコード配列に新機能追加時の追記が漏れていた）。左メニュー（`client-daily/src/components/layout/nav.ts`）
と揃うよう2項目を追加した。
検証: `server`/`client` の型チェック実行予定。

**プロジェクト管理（GPM）の詳細ヘッダー・ダッシュボード・新規作成フォームを、案件管理と同じ作法に揃えた**（PR③・[docs/design/v4/mockups/gpm-format-alignment.html](docs/design/v4/mockups/gpm-format-alignment.html) 項目7〜19。先行PR #574 で提案のみマージ、①言葉と色 ②一覧は別PR）。機能は変えていない（ステップ4/5の重複バグ修正のみ例外）。①**プロジェクト詳細ヘッダー**: タブ定義・段階判定を`projectDetail/tabs.ts`に切り出し各タブに`icon`を持たせた。PCのタブバーを`flex-1`の均等割りにし横スクロールをやめた（以前はPCが横スクロール・スマホが均等割りで逆だった）。ステージ帯に記号（C/B/A/R）を出し104px等幅にし、完了・失注は60px幅の別組・横に滑るレールに分離した（帯からは初めて失注にできるようになった。値そのものはPUTが元から受け付けていた既存の`ProjectStage`）。ヘッダー右上を主アクション「＋タスクを追加」に変え、右端に「最後の更新」を出し、期間・進み具合は本文先頭の事実の帯（`ProjectFactsBand`）へ移した。スマホはプロジェクト名を`truncate`でなく`[overflow-wrap:anywhere]`で折り返す。②**ダッシュボード**: 毎日開く画面なのでサブタイトルを外した（KPIの3段構成・パネルの「見る→」リンクは既に案件管理と同型だったため変更なし）。③**プロジェクトを作る**: 必須項目が欠けているとき欄の上に黄色い警告帯（文面はボタン名「作る」に合わせた）を出すようにし、「必須」表記（`text-destructive`のテキストと`*`の2通り）を共有`Field`部品の赤い`*`に統一した。各ステップを「いま必要な4つ（プロジェクト名・区分・依頼元・自社担当PM）＋あとから足せるもの（折りたたみ）」の2段構成にし、新規作成（`BasicStep`）と編集（`EditProjectDialog`）で欄の部品（`RequiredFields`/`MoreFields`/`ProjectFields.tsx`）を共有、編集側に無かった「いまの段」を読み取り専用で追加した（依頼元・区分は編集にも既にあったが見た目が違ったので統一）。ステップ4と5が同じ`OrgStep`を描いていた不具合を直し、5段目を実際に「確かめて作る」（入力内容の確認・`ReviewStep`）にした。見出し左に戻るボタンを配置した（`PageHeader`の`icon`）。検証: `npm run typecheck`・`npm run lint`・`shared`のVitest 1996件 全通過。実ブラウザでのPC/スマホ確認・`npm run verify:ui`は未実行。

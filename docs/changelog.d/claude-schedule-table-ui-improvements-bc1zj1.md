**スケジュール表のカードから左罫のアクセントをやめ、ドラッグ中の時刻・所要時間をその場で見えるようにし、「横串」（列をまたぐ項目）を足せるようにした**（9/6 ご依頼）。①項目カードの左端にあった列の色の縦線（border-left のアクセント）をやめ、列の色は見出しの丸だけで示すようにした。②カードをドラッグして動かす／下端を引っ張って伸縮させる間、いまの時刻（移動中は「開始–終了」、リサイズ中は「終了 HH:MM」）と所要が吹き出しで出るようにした（カードの中に置くと短い項目で切れるため、カードの外＝動いている辺の隣に出す）。③カードの中に「開始–終了 ・ 1時間30分」を常に出すようにした（高さが足りない短い項目は題名の右に所要だけ）。④**横串**——Excel のセル結合と同じように、全体朝礼・昼食のような項目を複数の列にまたいで1本で引けるようにした（`qsheet_schedule_items.span_cols`・migration 280。1=この列だけ／N=この列から右へN列／0=全列。「全列」は数ではなく意味で持つので、列を足しても横串が途切れない）。横串は列ごとの重なりレーンからは外し、列の外側に重ねた1枚（`ScheduleSpanLayer`）で描くので、横串が居るだけで他の項目が細くなることはない。Excel 書き出しも横方向のセル結合で同じ形に出し、項目一覧シートに「横串」列を足した。スマホの縦積みカードでは、どの列で絞り込んでいても横串を出す。検証: 新規マイグレーション（280番）を検証DBに適用、`server`/`client`/`client-techops` の型チェック、`shared` の Vitest 2004件（新規の `scheduleSpan.test.ts` 8件を含む）全通過。⑤**カードがかぶったときの見せ方**も直した（同日の追加ご依頼）。重ね順は**開始時刻の順**（遅く始まる＝画面の下にあるカードが手前）にし、**重なった所には文字を出さない**（各カードの文字は、手前に重なるカードの上端までしか描かない。残りが 14px 未満なら文字自体を出さず、題名はカードのツールチップで読める）。そのために**列の中のカードも横串も1枚の層にまとめて描く**ようにした（列ごとの `div` に分けたままだと「後の列が必ず手前」になり、時刻での重ね順を作れない）。位置・重ね順・文字を出してよい高さは `scheduleCardLayout.ts` の1関数が決め、`shared/tests/scheduleCardLayout.test.ts`（11件）で固定した。カードが列の外に出たことで `elementFromPoint`（単数）では列を辿れなくなるため、列をまたぐドラッグの当たり判定を `elementsFromPoint`（複数・重なりを全部見る）に直した（実ブラウザで B スタジオ→A スタジオの移動が保存されるところまで確認）。

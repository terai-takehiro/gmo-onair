**① 予定の週表で、札の上端でも延ばせて、掴んで動かせるようにした**。週表（`TimeGrid.tsx`）は下端のつまみを引く延長しか持たず、開始時刻をずらす・時間帯や曜日を動かすには「札を押す→詳細→編集→時刻を打ち直す」の4手が要った。①下端に加えて上端にもつまみを付け、開始時刻を延ばし縮めできるようにした（`useGridDrag.ts` の `resize` に `edge: 'start' | 'end'` を追加）。②札本体を掴んで動かすと、長さ（開始〜終了の間隔）を保ったまま時間・曜日をまとめてずらせるようにした（`move`。マウス位置の下にある列を `elementFromPoint` で拾い、日をまたぐ移動にも対応）。保存は3系統とも部分更新（動かした項目だけ送る）のまま、サーバー側の `isReversedTimeRange` チェックも従来どおり効く。ドラッグ操作か通常のクリック（詳細を開く）かは `wasDragged()` で区別し、動かした直後のクリックが誤って詳細を開かないようにした。検証: `npx tsc -b client`・`npm run lint`。

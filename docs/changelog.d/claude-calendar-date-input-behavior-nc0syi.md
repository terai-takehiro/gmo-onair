**① 予定の週表で、札の上端でも延ばせて、掴んで動かせるようにした**。週表（`TimeGrid.tsx`）は下端のつまみを引く延長しか持たず、開始時刻をずらす・時間帯や曜日を動かすには「札を押す→詳細→編集→時刻を打ち直す」の4手が要った。①下端に加えて上端にもつまみを付け、開始時刻を延ばし縮めできるようにした（`useGridDrag.ts` の `resize` に `edge: 'start' | 'end'` を追加）。②札本体を掴んで動かすと、長さ（開始〜終了の間隔）を保ったまま時間・曜日をまとめてずらせるようにした（`move`。マウス位置の下にある列を `elementFromPoint` で拾い、日をまたぐ移動にも対応）。保存は3系統とも部分更新（動かした項目だけ送る）のまま、サーバー側の `isReversedTimeRange` チェックも従来どおり効く。ドラッグ操作か通常のクリック（詳細を開く）かは `wasDragged()` で区別し、動かした直後のクリックが誤って詳細を開かないようにした。検証: `npx tsc -b client`・`npm run lint`。

**予約・予定の入力ダイアログ3つで、終了が開始より前でも保存できてしまう不具合を直し、日時のデフォルト値を足した**（`StudioBookingDialog.tsx`・`PersonalEventDialog.tsx`・`PartnerScheduleDialog.tsx`）。①終了日欄は `min` 属性しか持たず、`min` はカレンダー UI の選択しか止めない — 日付欄をキーボードで直接打ち直すと開始日より前の値でも通ってしまい、送信ボタンを押してもブラウザの標準検証に握りつぶされて **何も起きないように見える**不具合があった。終了日・終了時刻の `onChange` と送信前チェックの両方で開始との前後関係を見るようにした。②あわせて「複数日は開始日の翌日をデフォルトに」「終了時刻は開始時刻の1時間後に追従」というご要望に対応。複数日トグルを入れた瞬間・開始日を動かして終了日が開始日以前になった瞬間に終了日を翌日へ押し出し（スタジオ予約のみ。他の2画面は複数日トグルが無く、終了日欄が単日/複数日どちらの意味も兼ねる設計のため対象外）、終了時刻を手で直していない間は開始時刻を動かすと終了時刻が1時間後に追従するようにした（編集時・時刻付きプリセットは指定値を保つ）。日付・時刻の計算は `shared/src/client/format.ts` に `addDaysToDateStr`・`addMinutesToTimeStr` を足して3画面で共用。`StudioBookingDialog.tsx` は日時セクションを `BookingDateTimeSection.tsx` に切り出し（1ファイル400行のラチェット）。検証: `npx tsc -b client`・`npm run lint`・`npm run test`。

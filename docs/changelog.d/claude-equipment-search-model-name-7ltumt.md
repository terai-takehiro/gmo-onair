**機材管理のメンテナンス・貸出の機材検索プルダウンで、型名でも検索できるようにした**。
①メンテナンス記録の追加ダイアログ（`MaintenanceDialog.tsx`）と貸出登録の機材選択
（`LendingSelectStep.tsx`）は、機材ID（`eq_code`）・名前でしか検索できず、型名
（`model_number`）ではヒットしなかった（機材台帳・「探す」画面のサーバー検索は
既に型名対応済みだったが、この2画面はクライアント側の独自フィルタで型名を見ていなかった）。
どちらも検索条件に `model_number` を追加した。
②同名・同型の機材が複数台あると、機材ID（`eq_code`）だけでは現物の号機（`unit_number`
＝画面上の「No.」）が分からず区別できない、という指摘を受け、メンテナンス側の選択肢にも
型名・No. を表示（`subLabel` に `eq_code` / 型名 / `No.〜` を並べる）し、貸出側のカードにも
型名を表示するようにした（No. はもともと表示・検索対象だった）。
検証: `server`/`client`/`client-equipment` 等の型チェック、`shared` の Vitest 1996件、
`npm run lint` を実行し全通過。

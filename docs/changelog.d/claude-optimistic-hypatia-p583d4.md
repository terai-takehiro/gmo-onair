**会場図面の道具の帯を、わかりにくい用語と1文字ラベルから直した**（利用者からのご指摘）。
①道具の帯の「すいつき」「方眼」「ものさし」は、`docs/wording.md` ルール10（2026-09-13「通じるカタカナ語は、言い換えずそのまま使う」）で
運営マニュアル側は既に「スナップ」「グリッド」「ルーラー」に統一済みだったが、同日に書いた会場図面の設計書
（`docs/design/v4/venue-layout.md`）だけがこの決定を見落として古い語のまま実装してしまっていた。設計書・実装（`VenueToolbar.tsx` ほか）
の文言を「スナップ」「グリッド」「ルーラー」に、あわせて「重なり」（前面・背面）も運営マニュアルと同じ「重ね順」（最前面へ・最背面へ）に揃えた。
②図形ボタン（四角・丸・線・文字・寸法線）が漢字1文字だけでアイコンが無く、整列ボタンも「左・中央・右・上・中央・下」で「中央」が横用・縦用の
2つ並んでいて紛らわしかった。運営マニュアルの `ManualSelectionToolbar`・`BlockToolbar` で既に確立していたアイコン（`lucide-react`）と
ツールチップの部品・語（左そろえ・左右中央そろえ・右そろえ・上そろえ・上下中央そろえ・下そろえ・最前面へ・最背面へ）にそのまま揃え、
図形ボタンにも意味の伝わるアイコン（四角＝Square・丸＝Circle・線＝Slash・文字＝Type・寸法線＝ArrowLeftRight）を足した。
③あわせて「等間隔」ボタンの見た目のラベルが横方向専用なのに方向を示していなかったのを「横等間隔」に直した（機能は変えていない）。
検証: `npx tsc -b client-techops`・`npm run test`（`shared/tests/venueGeometry.test.ts`）・`npm run lint`。

**機材台帳（スマホ）の付属品カードに、個別に直す鉛筆ボタンを付けた**。親機材カードを開いて
出てくる付属品（子機材）の行は、タップすると詳細画面へ飛ぶだけで、その場で直す口が無かった
（PC の表は子の行にも「操作」列があり、そちらは鉛筆で直せていた）。`EquipmentCardRow.tsx` の
`onEdit` を「常に親を渡す」形から「渡された `EquipmentRecord` だけを直す」形に変え、親カードの
鉛筆は `entry.item`、開いた付属品の行の鉛筆は `kid` を渡すようにした。編集ダイアログ
（`EquipmentDialog`）は渡された1件だけを対象にするので、親を編集したら子までまとめて
書き換わる、といった事故は起きない。検証: `npm run typecheck` / `npm run lint` / `npm run test` OK。

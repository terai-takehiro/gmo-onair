**全アプリ共通のヘッダーに、PCで左メニュー（サイドバー）を隠すボタンを追加した。** これまでヘッダーにあったのはスマホ用ハンバーガー（`lg:hidden`）だけで、PC（≧1024px）では左メニューが常時固定表示され、隠す・畳む手段が無かった（過去に近い実装は `uiStore.ts` にあったが廃止済み `client-awards` 専用で、v4の共通シェルには配線されていなかった）。共通シェル（`shared/src/client/shell/`）の `AppShell` / `AppTopbar` / `AppSideMenu` に PC専用の折りたたみ状態を追加し、ヘッダーの新しいボタン（`PanelLeftClose`/`PanelLeftOpen`）で左メニューを幅0まで完全に隠せるようにした。隠した状態は `localStorage`（新規キー）に記憶し、次回アクセス時も維持する。共通シェルを使う配信中5アプリ（案件管理・日常業務・機材管理・制作技術支援・計時視聴者）全部に一度に効く。スマホの引き出し開閉（ハンバーガー）とは別の状態で、互いに影響しない。検証: `server`/`client`/`client-daily`/`client-equipment`/`client-techops`/`client-live` の型チェック、`npm run lint`。

**プロジェクト管理ダッシュボードのスマホで、「止まっているプロジェクト」等のカードが中身1行なのに1200px超の空白カードになっていたのを直した**（ユーザー報告「スマホのこれ中身ないのに長すぎない？」）。原因はカード部品（`gpm/pages/dashboard/Panel.tsx`）の `h-full`。PC（3列グリッド）では隣の「未確認事項」と高さを揃えるためのものだが、スマホ（1列）では「止まっているプロジェクト」「動いているプロジェクト」の2枚が同じ入れ物の中に縦に積まれる兄弟になり、`h-full`（`height:100%`）が「2枚合わせた入れ物の高さ」を基準に解決されるため、中身が1行しかない枚まで2枚分の高さに引き伸ばされていた。`h-full` を `lg:h-full` にし、PC では高さ703px/703pxで揃ったまま、スマホでは各カードがコンテンツ量どおりの高さ（実測: 空状態1200px超→179px、実データ3件/5件で473px/793px）になることを確認した。案件管理側の同型カード部品（`salesDashboard/Panel.tsx`）は各カードが直接グリッドの子として並ぶ別構造のため、同じ不具合は無いことを実測で確認済み。

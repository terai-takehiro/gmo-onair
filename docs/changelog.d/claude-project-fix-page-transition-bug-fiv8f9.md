共通部品 `Label`（`shared/src/client/ui/label.tsx`）が `leading-none`（行間ゼロ）だったため、
「回を足す」ダイアログの「回の単価（任意・確定売上）」のような長いラベルが、狭い画面幅・
大きめの文字サイズ設定で2行に折り返されると、行間が無く文字が重なって読めなくなっていた
（利用者からのスクリーンショットで報告・375px 幅で強制的に折り返させて実機再現）。
`Label` を `leading-tight` に直した（1行のときの見た目はほぼ変わらない・全アプリ共通部品なので
影響範囲は全体だが、折り返さない大多数のラベルは高さが数px増えるだけ）。

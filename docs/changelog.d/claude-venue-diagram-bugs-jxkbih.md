**会場図面の不具合6件を直した**（利用開始後の指摘）。①左パネルのタブ名「置く」「並べる」は
アプリの他画面（運営マニュアルの「追加」「差し込む」など）と語がそろっていなかったので、
`docs/design/v4/venue-layout.md` の語彙にすでにある名詞形に寄せて「追加」「並べ方」に統一した
（並べ方の「格子に並べる」も他の並べ方（劇場形式など）と同じ「◯◯形式」に）。ボタン・文言も同じ動詞に
そろえた。②タブを切り替えると盤を含む3列レイアウトが揺れていたのは、CSS Grid の既知の落とし穴——
固定幅の列でも中身の `min-content` がそれより広いと列が広がってしまう——で、左右の `<aside>` に
`min-w-0` が無かったのが原因。付けて直した。③④カメラのクレーンは TK-53AL だけを残し、TK-53A と
その専用台車 TI-04B（「53A 台車」）は追加メニューから外した（カタログの行自体は残すので、既存の
図面に置いてあれば表示は変わらない）。⑤「並べ方」タブのプレビューは幅と高さの両方を固定の
220×140 に収めようとしていたため、行数の多い並べ方ほど二重に縮んで品目が見えなくなっていた。
幅だけで縮尺を決め、高さはプレビューの箱ごと伸ばすようにした（左パネルは元々スクロールする）。
⑥並べ方で作ったグループを盤に置いたあと、グループごとつかんで動かしたつもりが1脚だけ動いて
しまっていた——ダブルクリックでない限りグループ全体を動かす設計（`docs/design/v4/venue-layout.md`
§4-6）に対し、実装はどのクリックでも常に1個だけを動かしていた。グループの他のメンバーもドラッグ
中に同じ量だけ一緒にずれて見えるようにし、指を離したときは全メンバーへ確定するようにした
（ダブルクリックで1個だけをつかんだ場合は今までどおりグループから外れる）。
検証: `npx tsc -b client-techops`・`npm run lint`・`npm test`。

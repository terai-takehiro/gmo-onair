**iOSネイティブ風モックアップに財務のスマホ画面とPC専用画面の試作を足し、キャンバスを画面ごとに分割した（コード変更なし）。**
前回（PR #269）の案件管理まわりに続き、財務管理のスマホ実画面「取引先」（仕入先／
パートナー一覧）を同じ調子で追加した。あわせて、PC専用と判断されている画面
（案件管理の「見積・請求」）をサイドバー・トップバー込みのデスクトップサイズで
再現する試作を始めた。⚠️ ユーザーから「PC専用画面もスマホ対応していく」という
方針転換の意向が示された（実装ポリシー `pcOnlyScreens.ts` 自体はまだ変更していない・
意向の記録のみ）。続けて、方針転換を受けた初期案として「見積・請求」のスマホ版試作
（BillingMobile・表をやめてカード化し、金額の桁の読み違えを防ぐ構成）も追加した
（実画面の再現ではなく確認前の叩き台であることを明記済み）。
1つのキャンバスに複数画面を詰め込むとスマホの Safari で繰り返しクラッシュしたため、
**最終的に「1モックアップ＝1キャンバス」へ分割した**（ユーザーからの明示の指示）。

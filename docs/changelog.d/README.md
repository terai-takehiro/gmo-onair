# `docs/changelog.d/` — 版に載せる1行を、PR ごとに1ファイルで置く場所

**作業 PR はここにファイルを1つ足すだけ。** `CLAUDE.md` の「現在のバージョン」・
`README.md` の版・`package.json` の `version` は**触りません**。

## なぜこの形にしたか（実測）

直近2週間で **`CLAUDE.md` は 55 コミット・`README.md` は 42・`package.json` は 45** 動いており、
**PR のたびに同じ3か所を書き換えて**いました。しかも書き足す場所が
「履歴のいちばん上」なので、**2本を並行して出すと必ずぶつかります**
（実際に #124 と #125 で 5 回、`main` を取り込み直して直しました）。

ぶつかったのは**毎回この3か所だけ**で、コードは1度も競合していません。
つまり**衝突は作業の中身ではなく、版の付け方が作っていた**ということです。

- **版の番号は「枝を切った時刻」ではなく「マージされた順」で決まる**ものなので、
  作業を始めた時点で番号を取ると、先にマージされた別の PR と必ず取り合いになります
  （#123 が先に入って v4.0.27 を使い、こちらの2本が同じ番号を取っていました）
- ファイルを分ければ**同じ行を2人が書かない**ので、衝突しようがありません

## 書き方

ファイル名は**枝の名前**（`/` は `-` に）。中身は**そのまま版の履歴に載る1行**です。

```
docs/changelog.d/fix-codex-mobile-p2.md
```

```markdown
**スマホから古い未入金が見えなかったのを直した**（Codex のレビュー棚卸し #61）。
①⚠️ **先月以前の未入金が1件も出ていませんでした** — 今月の締めだけを引いていたためで…
```

- **先頭に `vX.Y.Z —` を書かないこと。** 番号はリリースのときに決まります
- **先頭は `**太字の見出し**` で始めること。** 画面の「バージョン履歴」は
  **先頭の太字を版の名前として切り出します**（太字で始めないと本文の頭 90 文字が名前になります）
- 書式は今までの履歴と同じ（**何が起きていたか → なぜ困るか → どう直したか → 検証**）
- **1 PR = 1 ファイル。** 直しが増えたら同じファイルに書き足します
- ⚠️ **1本 3,000 バイトを目安にしてください**（超えると `release:notes` が警告します。
  **止めはしません** — 長い下書きにも書くべき中身はあるので、リリースの日に人の文章を
  削らせないためです）。理由は次の節

## ⚠️ 長さの上限（12,000 バイト／1つの版）

`CLAUDE.md` の「## 現在のバージョン」は**毎ターン文脈に載る**ので、貯めると
**全作業のコストが上がります**（v3.2.2 の時点で 680KB ＝ 本文の 96% が履歴でした）。
そのため `collect-changelog.mjs` は**版1件ぶんの行**に 12,000 バイトの上限を持っています。

**超えたときは自動で分けます**（v4.1.3 から。それまでは `exit 1` で止まるだけでした）:

- **全文** → `docs/version-history.md`「## 過去のバージョン」直下（`(…)` で包んだ1行）
- **要約** → `CLAUDE.md` と `README.md`（同じ版番号で始める）

画面の「バージョン履歴」は両方を読み、**同じ版なら長いほう（＝全文）を本文に、
見出しは要約のもの**を出します。**中身は1文字も失われません。**

### 要約は人が書いてください（`_summary.md`）

`docs/changelog.d/_summary.md` を置くと、**その中身をそのまま**要約に使います
（**下書きとしては集めません**）。無いときは**収録した見出しを並べたもの**が入ります。

⚠️ **機械にできるのは「何が入っているか」を並べることだけ**で、
**「その版が何だったか」を1文で言うのは人の仕事**です。自動の要約が入ったときは
`release:notes` が警告を出すので、**出す前に `CLAUDE.md` の先頭の行を読み直してください**。

## リリースのとき

```bash
npm run release:notes -- 4.0.30     # 集めて CLAUDE.md に積む（4件目はアーカイブへ）
```

`docs/changelog.d/*.md` を**マージされた順**（ファイルの更新時刻ではなく git の履歴順）で集め、
1つの版として `CLAUDE.md` の先頭に置き、`README.md` と `package.json` を上げ、
**集めたファイルを消します**。あとは `npm run check:version` が3か所の一致を確かめます。

**デイリーニュース報告を「日ごとのページ」から「月ごとの1ページ」に集約し、UI崩れを直した**。
①調査（3体の並列サブエージェント）で見つけた不具合を修正: `NewsRow`（`news/NewsRows.tsx`）は
`isMobile`（`lg`=1023px 境界）が false のときしか描画されないのに、内部に `sm`(640px) 境界の
レスポンシブ指定（`hideOnMobile`/`stackOnMobile`）が残っており、常にデスクトップ扱いのまま
到達しないデッドコードになっていた（削除。見た目は変えていない）。また画面の主アクション
（「ニュースを追加」）は `PageHeader` 側の `sm` 境界で PC/スマホの置き場所が切り替わるのに、
日付ナビの帯は `isMobile`（`lg` 境界）で `w-full` にしており、640〜1023px 幅でボタンが
見出し直下に孤立して折り返されていた（帯側も `sm` に揃えて解消）。
②画面を月表示に作り替えた。以前は日付ナビで1日ぶんだけを表示し、前の日を見るには1日ずつ
戻るしかなかった。月単位で1ページに集約し、日付は表の中の見出し行として並べる、ひと続きの
表の形にした（新設 `GET /dailyops/reports/items-by-month`）。機能はそのまま
（絞り込みチップ・注目度・週報へ送る・編集・削除・「確認した」は日ごとの見出し行に残した）。
「週報へ送れるか」（送り先の週が確定済みか）は月をまたぐと行ごとに送り先の週が違うため、
ページ単位の1つの値からサーバーが行ごとに計算する `weekly_locked` に変えた。
ニュースを追加する画面には日付欄を足した（「いま開いている日」が無くなったため）。
③AI からの投稿経路（MCP `add_ops_report_items(kind='daily_news')`）は変更なし。月表示に
なっても行の追加先は「その日のレポート」のまま。

**案件Excel一括登録で、旧GLS番号付きの過去データを取り込むと案件番号の履歴が残らなかったのを直した**（terai-takehiro/gmo-onair#714・#716で決算取込を直したのと同型の穴を、実害調査の過程で自主点検して発見）。案件Excel一括登録（テンプレートの「旧案件サンプル（過去データ取り込み例）」の通り、GLS番号を指定して新規案件を作る使い方）で作成した案件は `projects.gls_number` に番号を書くだけで `project_numbers` に履歴を残しておらず、後日その案件を改番すると「退役させる現役の番号」が見つからず旧番号が跡形もなく消え、以後どこからも引けなくなる恐れがあった。決算取込を直した#716と同じ形（新規作成の直後に、番号の見た目から `scheme`/`entity_code` を判定して1行記録）で `excel.routes.ts` の `PROJECTS_CONFIG.insert` を直した。あわせて本番DB（`onair_prod`）を実機監査し、この系統の不具合による実害（過去に旧番号が実際に失われた案件）が無いことも確認済み。検証用Postgres上で、旧方式番号・新方式番号（`SCS-`等）・番号なしの3パターンを実際にINSERTし、`project_numbers` が意図通り作られる（または作られない）ことを確認した。

**受付レールで「失注にする」を押すと画面が飛んでしまい、次々に見送れなかったのを直した**。案件作成画面（受付を統合した画面）で自動で届いた引き合いを「失注にする」（見送る）と、押すたびに `/sales/dashboard` へ強制的に遷移していた（`useCreateProject.ts` の `drop` ミューテーション）。複数件を続けて見送る作業のたびに画面が飛び、都度レールへ戻る手間になっていた。押したあとは画面を移動せず、選択を外す（`?inquiry=` も付いていれば URL から外す）だけにし、レールの続きをそのまま選べるようにした。検証: `npx tsc -b client`・`npx eslint` とも該当ファイルはエラーなし。

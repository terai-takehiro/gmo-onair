①⚠️ **合計金額の「¥」だけが行の左端に取り残され、数字が画面の右端まで飛んでいました。**
`<Money>` の**既定は列で使う形**（枠いっぱいに `¥` を左端・数字を右端へ引き離して、
縦に並べたとき金額の右端をそろえる）なので、**文中に置くと `¥` と数字が引き離されます**。
実測で**この1つの金額が 1041px** を占めていました（正しくは 67px）。
`Money` の説明にも「縦に1つしか無い金額に当てると円記号だけが遠くに離れて見える
（利用者からのご指摘。案件詳細の「見積金額」がこれだった）」と書いてある形で、
**同じ間違いを2度目に踏んでいた**ことになります。`inline` を渡して直しました。

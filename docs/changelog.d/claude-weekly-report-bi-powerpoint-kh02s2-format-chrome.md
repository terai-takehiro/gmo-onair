**隔週キープの資料のヘッダー・フッター・ロゴを、GMO流会議フォーマット Ver.2.5 の実物の pptx から取り込んだ**（ご依頼「添付の実物から抽出、ロゴデータもちゃんと取る」）。これまで題・帯・フッターの位置と色は現行資料を見て手で寄せた近似値で、ロゴは文字（GMO INTERNET GROUP）、帯のスピーカーは lucide の絵、フッターには実物に無い罫線があった。実物（適用開始 2025/10/24）を unzip して、スライドマスター・レイアウト・報告ページの XML から題（0.234in/0.124in・9.817×0.707in・36pt）・帯 2 本（0.86in／1.422in・13.003×0.449in・18pt）・フッター（ワードマーク／青いタグ 10pt／Strictly confidential 12pt／ページ番号 24pt）・表紙（72／40／24／20pt の 5 つの箱）・Appendix（54pt）・締め（すべての人にインターネット）の位置をインチで読み、`shared/src/keepReport/templates.ts` の `FORMAT_CHROME` を正にして pptx 出力はそのまま・画面のプレビューは % に換算して同じ位置で描くようにした。ワードマーク・タグライン・帯のスピーカーは実物の SVG をそのまま `formatAssets.ts` に持ち、pptx では PNG を置いてから出力後に元の SVG を結びつける（pptxgenjs が Node で SVG を扱えないため。`keep-pptx-svg.service.ts`・`jszip` を追加）。帯を実物の高さにしたので部品の上端を帯の下（27%）に下げ、締めのページ `closing` を標準の構成の最後に足し、ページ番号はスライド番号のフィールドにした（PowerPoint で並べ替えても振り直される）。あわせて、⚠️ 資料の組み直し（次の会議日の資料・「数字を更新」）が部品の位置を無条件に前の版から引き継いでいたため、テンプレを直しても古い位置のまま組まれて題と見出しが帯の下に潜っていた（実ブラウザで実測）のを直した — 人が右の「このページ」で位置を直した部品だけ `options.moved` の印を付けて前の版の位置を残し、ほかはテンプレの今の位置に揃える（固定ページの部品も同じ）。検証: `npm run typecheck:all`、`npm run lint`、`shared` の Vitest（枠と部品が重ならないことを見る `keepReportFormatChrome.test.ts` と、shared／server の写しの一致を見る parity テストを足した）、サンプルのパックから pptx を出して XML で svgBlip の結びつきと位置を確認（pptx skill の validate.py も通過）、実ブラウザ（Playwright）で「資料をつくる」の表紙・帯つきページ・数値報告・Appendix・締めを撮って確認。⚠️ この環境には LibreOffice Impress が無く pptx を絵にできないため、**PowerPoint で開いた見た目は未確認**（検証環境の「資料をつくる」から出して確認が要る）。

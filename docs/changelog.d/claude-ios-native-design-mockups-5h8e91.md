**iOSネイティブ風のスマホ見た目を、Claude Designのキャンバスで探索した（コード変更なし）。**
案件管理まわりの実装済みスマホ画面（トップ・ダッシュボード・案件一覧・やること・
案件詳細・案件をつくる・入金の確認・探す）を、文言・並び・判定は実装のまま、
見た目と手触りだけをiOSネイティブの作法（角丸・余白・ナビゲーションの形・
下から出るシート）に寄せて作り直した。共通部品として NavBar／TabBar／ListRow／Sheet
の4つを切り出してある。ブランド色・書体・`mobile.md` の情報設計（下タブ3本・
スワイプに意味を持たせない等）は変えていない。キャンバスへのリンクと引き継ぎメモは
[`docs/design/v4/ios-native-mobile-mockups.md`](../docs/design/v4/ios-native-mobile-mockups.md)。

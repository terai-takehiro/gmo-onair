**プロジェクト管理（GPM）のスマホUIの崩れを直し、スケジュール管理を本格化した**（ユーザー報告「UIがめちゃめちゃ崩れてる。スマホ版が特に」「ガントチャートを含め必要な機能が実装されていない」）。①スマホUI: 詳細ヘッダーでタブとステージ切替が同じ行に押し込まれ文字が重なって読めなかったのを直した（原因はタブ枠の `flex-1`＝flex-basis 0 が折り返し計算で幅0と数えられること — PageHeader の v4.5.1 と同型。スマホはステージを全幅4等分・タブをその下の全幅の行に縦積み）。工程・タスクの行は表の列の折り返しをやめてスマホ専用の2行カード（`PhaseCard`/`TaskCard`・PCの行と同じpropsを共用）にし、44px未満だった戻る/鉛筆も44pxにした。②ガント本格化（PMツールのディープリサーチに基づく— 小規模工事チームに効くのは FS依存・連鎖リスケ・遅延可視化・ズームで、CPM/EVM/フルベースラインは過剰と結論）: 初期表示で今日線が必ず視野に入るようにし（従来は開始日起点で進行中案件のバーが1本も見えず「実装されていない」ように見えた根本原因）、ズーム（日24px/週12px/月4px）と「今日へ」、土日の陰影（月ズームでは消す）、期限超過の工程・タスクの赤枠＋「N日遅れ」バッジ、工程バーの進捗塗りをタスク完了数から計算（従来は二値）、**先行→後続（FS）の依存関係の矢印表示**を追加した。依存は案件タスクと同じ `task_dependencies` を読むだけ（GPMタスク＝`project_tasks` の行なのでサーバー変更なし）。先行タスクをうしろへドラッグすると「後続N件もずらすか」を**確認してから**一括シフトする（完了済みは動かさない・黙って動かすと不信を生むというMS Projectの教訓）。1日幅バーが両端のリサイズ掴みで埋まって移動できなかった実バグも修正。③タスク編集ダイアログに開始日・進み具合%・◆マイルストーン・先行タスク（追加/削除）を追加（従来はドラッグとMCPからしか触れなかった）。④スマホに「工程表」（縦タイムライン）を新設 — ガントの縮小移植はせず（Monday/TeamGantt/ANDPADと同じ判断）、工程を縦に並べて今日線・状態・遅れ・止まっている理由（未確認事項）・期限超過タスクのチップ（押すと直せる）・◆を1画面で読める形にした。概要タブの切り替えはスマホ＝リスト/工程表・PC＝リスト/ガント/かんばん。遅れの要約（「遅れ2工程・期限超過5件」）を切り替えの横に常時表示。検証: 実ブラウザ（Playwright＋検証Postgres）でズーム3段・依存矢印・連鎖シフト（DBの日付移動まで実測）・スマホ375pxの工程表・既存リスト/かんばんの無回帰を確認、`npm run typecheck`・`test`（1570件）・`lint` 緑。

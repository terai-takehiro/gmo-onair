**プロジェクト管理（GPM）のスマホUIの崩れを直した**（ユーザー報告「プロジェクト管理のアプリのUIがめちゃめちゃ崩れてる。スマホ版が特に」）。実ブラウザ（Playwright + 検証用Postgres）で全11画面を 375/768/1280px で撮って崩れを実測し、モックアップを起こしてから直した。①プロジェクト詳細のヘッダーで、タブとステージ切替が同じ行に押し込まれて文字が重なり読めなくなっていたのを直した（原因はタブ枠の `flex-1`＝flex-basis 0 が折り返し計算で幅0と数えられ、約260pxのステージ帯と同居させられていたこと — PageHeader の v4.5.1 と同型。スマホはステージを全幅4等分のセグメント・タブをその下の全幅の行に縦積みにした）。②概要タブの工程・タスクの行が、表の列をそのまま折り返した結果バラバラに散らばり、操作ボタン（スマホでは各44px）が 96px/56px の固定枠を突き破って隣の列に重なっていたのを、スマホ専用の2行カード（1行目=名前+状態／2行目=補足+操作）に作り直した（`PhaseCard`/`TaskCard`・PC の行と同じ props を共用）。③詳細ヘッダーの戻る（40px）と鉛筆（36px）を44pxに。④プロジェクト一覧で PC→スマホの幅変更時にボードが1コマだけ描かれる競合を `effectiveView`（概要タブのガントと同じ形）で塞ぎ、体制タブのグリッドに `grid-cols-1` の基底を足した。検証: 修正後を 375/768/1280px で再撮影し、ヘッダー・工程・タスクの重なりが消えたこと、PC の見た目（リスト/ガント/かんばん）に変化がないことを確認。

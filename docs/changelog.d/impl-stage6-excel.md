制作資料の台本Excel入出力（段6）を実装した。今まで「Excel出力」を名乗りながら実体は
`.csv`（セクション名の完全一致でしか列を拾えず、CM・VTR・ロール尺・マイク香盤のOFFが
落ちる）で、サイドバーの「Excel入出力」2ボタンは押しても無反応だった状態を、実際の
`.xlsx`（ExcelJS・2行ヘッダー＝1行目日本語見出し・2行目非表示の機械キー）に格上げした。
書き出しはサーバー1箇所（`server/src/contexts/qsheet/excel/`）に集約し、進行台本・
マイク香盤（ON/STBY/OFFを表現できる）・LEDシーン・立ち位置図・マスター・台本情報の
各シートを持つ。取込は既定「差分マージ」（ID列が一致する行だけ更新し、ファイルに無い
既存行は残す）＋「末尾に追加」の2モードのみとし、危険な「すべて置き換え」は廃止した。
サーバーは`qsheet_documents.data`を直接書かず操作リスト（PlanOp[]）だけを返し、
クライアントが既存の`applyDataUpdate`経由で適用する（同時編集で入った行を黙って消さない
設計）。取込前スナップショットを`qsheet_import_batches`に残し、24時間・直近1件まで
ワンクリックで取り消せる。11ブロック型のうち10型（`slide`のみ画像そのものが対象で往復不可）
が書き出し↔取込で往復する。08（機器設定のExcel）とは別モジュール・別ライブラリのまま。

**意図して寝かせているネタが、案件台帳から消えてしまうのを直した**（#495 のマージ後に自分の差分を読み返して見つけた実バグ・利用者への影響は出ていない）。ゴミ案件の片づけで「放置ネタ」を選ぶ条件に、**自動見送りが掛けている「生存証拠」の除外（`ALIVE_EVIDENCE_SQL`）が入っていなかった**。⚠️ **これが抜けると「機械が閉じにも来ない案件を、台帳からは消す」という食い違いが起きる** — 自動見送り（`autoLoseStaleNeta`）は①未来の日付までスヌーズしてある②期限が今日以降の次の一手がある③期日が今日以降の未完了タスクがある④本番日が今日以降、のどれかに当たるネタを対象から外しているが、こちらは日数（90日）しか見ていなかった。**スヌーズは `updated_at` を古いままにし得る** — 100日前に「来月まで寝かせる」と設定したネタは、意図して寝かせているのに `updated_at` が200日前になり、条件に当たってしまう。失注側には掛けない（すでに閉じた案件に生存証拠が残っていても、それは片づけ忘れであって「生きている」ことではないため）。検証: 実 Postgres で①未来スヌーズ→対象外②スヌーズ切れ→また対象③本番日が未来→対象外④生存証拠なし→また対象、の4通りを確認。`npm run typecheck:all` 緑、`npm run test` 1744件緑（この機能は22→23件）、`npm run lint` 緑。あわせて、この除外を確かめるテストが `pt.is_completed = false` の中の `s_completed` に当たって嘘の失敗をしていたので、ステージ名を引用符ごと見る形に直した。

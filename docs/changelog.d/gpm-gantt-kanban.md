**プロジェクト管理（GPM）にガントチャートとかんばんを載せ、MCP をガントの細部編集に対応させた**（ユーザー指摘「むしろガントチャート、カンバン管理が必要なのはプロジェクト管理」）。プロジェクト詳細の概要タブに見え方の切り替え（リスト／ガント／かんばん・PC のみ）を追加した。①**ガント**は工程（`gpm_phases` の開始・終了日）とタスクを1本の時間軸に出し、バーのドラッグで日程ごと移動・端をつまんで期間変更ができる（工程は `PUT /gpm/phases/:id` の部分更新・タスクは `start_date`/`due_date`。開始日の無いタスクを動かしたときは期限だけ動かし「期限だけ決めてある」形を壊さない）。◆マイルストーン・進捗%の塗り・今日線つき。②**かんばん**は工程を列・タスクをカードにし、ドラッグで工程の付け替え（`gpm_phase_id`）・カードで完了チェック・列ごとの「タスクを足す」ができる（案件側の自由カラムは持ち込まない — 工程と食い違う第2の分類を作らないため）。③**MCP**: `list_gpm_tasks`/`get` が `start_date`/`progress`/`is_milestone` を返すようになり、`create_gpm_task`/`update_gpm_task` がガント用の細部（開始日・進捗%・◆・止まり方 `work_state`・並び `sort_order`）をそのまま受ける（従来は「案件タスク側の `update_task` で」と迂回させていた）。GPM の作成時に旧 `due_date` 列にも期限を書くようにし、案件詳細側ガントで「未スケジュール」に見えた食い違いも直した。AI 起票タスクの修正差分（`gpm-ai-feedback`）にも開始日・マイルストーンを追加し、AI がひいた線表を人がどう直したかがループに乗る。

**管理権限の単純化に向けた計画をまとめた**（コード変更なし）。ユーザーから「管理権限が
アプリ単位で分かりにくい、シンプルにしたい」との指示を受け、現状の権限モデル
（アプリ内部12区画・型と個人ごとの例外設定の2階建て・311/272箇所に分散した判定）を
整理し、`docs/reviews/permission-model-simplification-plan.md` に目標の形（区画を
ブロックアプリ単位の7つに統合・型のみに一本化）と実装フェーズを記録した。
⚠️ 凍結4アプリ（Qシート・技術資料・計時LIVE・リアルタイムCG）の権限は現状すべて
個人ごとの例外設定でのみ付与されており、実データを見ずに型ベースの解決へ切り替えると
アクセスできなくなる人が出るリスクがあるため、実データ監査（検証/本番の
`user_permissions` の中身の確認）を挟んでからコード実装に入る計画とした。
このセッションは検証/本番DBへ直接アクセスできないため、監査は次のステップとして
ユーザー側の対応を仰ぐ形で明記した。

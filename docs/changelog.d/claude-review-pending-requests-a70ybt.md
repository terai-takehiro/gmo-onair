**案件詳細に「回」タブを戻し、案件詳細・「案件を直す」が開くたびに読み直すようにした**（ユーザー報告「エピソードタブがいまだに案件管理の個別ページに出ない」「案件を直すがやはりリロードしないと正しいものが出ない」）。⚠️ **回（エピソード）は 2026-08 にモックの7タブに合わせてタブごと外し、回の表と「回を足す」はタスクタブの折りたたみの中に隠れていた**。9/2 の仕様変更で回ごとに見積・売上・請求を持つことになり回が案件の主役になったのに、開く手段が折りたたみの中にしか無く「出ない」と受け取られていた（実際に出ていない）。レギュラー（回を持つ）案件にだけ「回」タブを並べ、単発案件は今までどおり7タブのままにした（旧 URL `/episodes` もこのタブへ転送）。⚠️ **「案件を直す」の古い値は react-query の60秒キャッシュが原因** — 案件詳細で読んだ直後に直す画面へ移ると、キャッシュの値が欄に入ったまま再取得されず、その間に MCP（Claude）・別のタブ・別の人が直した値はリロードするまで出なかった（実ブラウザで再現: 裏で案件名を変えたあと SPA 内で「詳細 → 直す」と移っても古い名前のまま）。案件詳細と直す画面の案件の読み込みを「開くたびに必ず読み直す」（`refetchOnMount: 'always'`・キャッシュがあれば先に出して裏で差し替え）にし、案件を切り替えたときにフォームごと作り直す `key` も足した。あわせて財務ダッシュボード「台帳をひらく」の引き継ぎ日付が `2026-04-31` のような存在しない月末になっていたのを実在の月末日にした。検証: 検証用 Postgres＋実サーバーで Playwright により再現→修正後は SPA 遷移だけで最新の値が出ること、レギュラー案件で「回」タブが出て単発案件では出ないことを確認。

**「v4.5.19 で直したはずが直っていない」と報告された11項目を、原因まで遡って直した**（マルチエージェント）。⚠️ **未対応の大半は1つの取り違えから来ていた** — v4.5.19 の実装者が「グループ内案件」を**プロジェクト管理(GPM)**だと解釈し、定価の編集欄とカテゴリ別値引きを有効にする `allowListPriceEdit` / `allowCategoryDiscount` を GPM の見積タブからだけ渡していた。部品自体は案件管理側にあるのに prop が渡っておらず、ユーザーが見る案件管理の見積タブには何も出ていなかった（コード中のコメントにも「グループ内案件（GPM）」という誤解が複数箇所に残っていたので、それも直した）。正しい定義は `projects.customer_type === 'internal'`。⚠️ **「入力は出来るが保存ができない」の正体は保存ボタンが押せないこと** — 案件詳細の売上・請求ペインの編集ダイアログが、編集中の行ではなく「案件名で検索し直した結果」から必須項目を解決する作りで、解決できないと押せなかった（型 `RevenueRow` が `customer_id` を落としていたため。サーバーは返していた）。⚠️ **GLS 発番できない案件の原因を本番データで特定した** — BLVCKOUT ＝ OPP-202609-0002 は同一案件で `stage='c_proposal'`。`neta`/`d_hold`/`c_proposal` を除外するガードに当たり、エラーも出ず「新しい番組」カードが押せないまま「いまある案件に足す」へ強制的に切り替わっていた。C 見積提案から発番できるようにし、押せないときは理由を画面に出すようにした（発番でステージを自動昇格させる挙動は外した — 嘘のファネルを作らないため）。⚠️ **回（エピソード）は日付と番号を同時に指定する経路がどこにも無かった** — 「話数で指定」は番号を打てるが INSERT に収録日が無く、「頻度で作る」は日付は入るが番号が自動採番のみ。「9/7｜#17,18,19」のように**日付と回番号をまとめて登録**できるようにし、作成後に収録日・放送日を直す口も付けた。ほかに、財務ダッシュボードの売上内訳の行クリックを案件管理への遷移から画面内の案件絞り込み（URL の `?project_id=`）に変更、仕入・販管費の内訳に台帳と同じ3値の申請ステータスと精算ページへのリンクを追加、台帳の「案件を開く」矢印リンクを削除、ダッシュボードから台帳へ引き継いだ月が計上月欄に出るよう修正、見積明細の備考を改行できるように（見積書・検収書にも反映）、見積書PDFの値引きをカテゴリ毎の小計に分割（合計は1円も動かない）。検証: typecheck:all・lint・shared テスト1957件・build:changed 全通過。

**案件詳細に「回」タブを戻し、案件詳細・「案件を直す」が開くたびに読み直すようにした**（ユーザー報告「エピソードタブがいまだに案件管理の個別ページに出ない」「案件を直すがやはりリロードしないと正しいものが出ない」）。⚠️ **回（エピソード）は 2026-08 にモックの7タブに合わせてタブごと外し、回の表と「回を足す」はタスクタブの折りたたみの中に隠れていた**。9/2 の仕様変更で回ごとに見積・売上・請求を持つことになり回が案件の主役になったのに、開く手段が折りたたみの中にしか無く「出ない」と受け取られていた（実際に出ていない）。レギュラー（回を持つ）案件にだけ「回」タブを並べ、単発案件は今までどおり7タブのままにした（旧 URL `/episodes` もこのタブへ転送）。⚠️ **「案件を直す」の古い値は react-query の60秒キャッシュが原因** — 案件詳細で読んだ直後に直す画面へ移ると、キャッシュの値が欄に入ったまま再取得されず、その間に MCP（Claude）・別のタブ・別の人が直した値はリロードするまで出なかった（実ブラウザで再現: 裏で案件名を変えたあと SPA 内で「詳細 → 直す」と移っても古い名前のまま）。案件詳細と直す画面の案件の読み込みを「開くたびに必ず読み直す」（`refetchOnMount: 'always'`・キャッシュがあれば先に出して裏で差し替え）にし、案件を切り替えたときにフォームごと作り直す `key` も足した。あわせて財務ダッシュボード「台帳をひらく」の引き継ぎ日付が `2026-04-31` のような存在しない月末になっていたのを実在の月末日にした。検証: 検証用 Postgres＋実サーバーで Playwright により再現→修正後は SPA 遷移だけで最新の値が出ること、レギュラー案件で「回」タブが出て単発案件では出ないことを確認。

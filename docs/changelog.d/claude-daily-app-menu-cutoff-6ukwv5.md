**トップページの「日常業務」タイルから開くミニアプリの畳みが途中で切れて見えていたのを直した**。
①週報・ニュース・受領書類・内覧会・セキュリティカードなど6項目あるミニアプリの一覧のうち、
下のほうの項目が「今日」セクション（`TodayCard`/`TaskHubCard`）に隠されて欠けて見えていた。
②原因はスタッキングコンテキストの取り合い。トップページのスクロール演出（`Reveal`）が
一度だけ `transform` を使うアニメーションを再生するが、`animation-fill-mode: both` により
再生後も要素に暗黙のスタッキングコンテキスト（z-index:auto 相当）が残り続ける。
「アプリ」セクションと「今日」セクションはどちらも別々の `Reveal` で独立したコンテキストに
なるため、z-index:auto 同士は DOM の後ろにある側（＝今日）が手前に描かれてしまい、
ミニアプリの畳み自体は `z-20` を持っていても不透明な背景（`bg-card`）の「今日」の下に
潜っていた（ミニアプリ側の overflow/position の設定に問題は無かった）。
③「アプリ」セクションを包む `Reveal` に明示的に `relative z-10` を与え、
「今日」より必ず手前に描かれるようにした（レイアウト・見た目は変えていない）。

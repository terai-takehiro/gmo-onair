**総勘定元帳インポート（決算取込）の取込元を BOX から PC アップロードに変更した**。
①これまで「財務管理＞決算取込」の画面（`GlTab.tsx`）は Box のフォルダ ID・ファイル ID を入力欄で受け取り、
サーバー側で Box から総勘定元帳（freee の CSV または MoneyForward の xlsx）をダウンロードして取り込んでいた。
今回この Box 連携をやめ、画面から総勘定元帳ファイルをドラッグ＆ドロップ、またはクリックして選択し、
PC から直接アップロードする方式（`multipart/form-data`）に変更した。CLI 版（`import-kessan-dev.mjs`）も
`--file=<path>` でローカルファイルを指定する形に合わせた。
②取込先の判定・`scope`（販管費／売上／仕入／全部）や「マスタ作成」「固定原価除外」「重複スキップ」といった
オプション、抽出・投入のロジック自体（`kessan-import.service.ts`）は変更していない。
その上で、**対象月ぶんのデータは取り込むたびに完全に上書きし、元帳に含まれない既存データ（手入力など）は
マージされたまま残る**という従来からの挙動が変わっていないことをコードで確認した。

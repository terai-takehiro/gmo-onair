**① 予定のスマホ表示を、iPhone のカレンダーアプリに寄せた見た目に作り直した（モバイル「予定」）。**
旧実装は「その日ぶんの縦並び」だけで月表が無く、予約を作る導線も「部屋の空きを見る」へ送るだけ
だった（`StudioBookingDialog` の入力欄が多いことを理由に、スマホでは作らせていなかった）。
① 予定の PC 版と同じ**月表（数字＋点だけ）＋当日アジェンダ**にし、承認済みのモック
（iPhone カレンダー風）に合わせた。レイヤーの記憶（スタジオ・パートナー・自分）を PC・
スマホで共有する仕組み（`calendar/layerPrefs.ts`）を新設し、PC で外したレイヤーがスマホでは
出たままになる食い違いを防いだ。`StudioBookingDialog` を確かめ直すと `maxHeight: calc(92dvh - 56px)`
でスマホでもスクロールする作りだったため、この画面にも「予定を入れる」を追加し、PC と同じ
`NewEventChooser` → 3つのダイアログ（部屋を押さえる／自分の予定／パートナーの予定）を
そのまま呼ぶ。機材の出庫・返却の枠（旧⑩今日の現場を畳んだもの）は選んだ日に連動させて維持し、
「部屋の空きを見る」への導線（PC専用の②部屋の空きへ）も残した。
検証: `npx tsc -b client` / `npm run lint` / `npm run test` OK。

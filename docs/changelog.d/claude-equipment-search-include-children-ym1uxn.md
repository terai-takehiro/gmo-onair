**機材管理: メンテナンスの機材選びに付属品（子機材）を出し、保管場所の設定と機材台帳の崩れを直した**。①メンテナンスの「記録を追加」で選べる機材が**親機材だけ**で、カメラセットの中のレンズやマイクの1本といった**付属品（子機材）が候補に1つも出ませんでした**（`GET /equipment/items` は台帳を木で見せる都合で既定が `parent_id IS NULL`）。`include_children=1` を渡して子機材も候補に含め、候補と一覧の両方に**親の機材名**を添えました（「レンズ」だけではどのセットの1本か分からないため。親の名前で検索しても子が当たります）。問い合わせの鍵は機材詳細の「親だけ」の一覧と分けています（同じ鍵だと、どちらが先に走ったかで候補が変わる）。②設定＞保管場所で、**拠点名の札が右隣の保管場所名に重なっていました**（拠点の列が 56px なのに「GMOグローバルスタジオ」が約 120px）。列を 128px にして 1024px 以上でだけ出し（狭い側では保管場所名の下の行に出す）、`TableBadge` 自体も**あふれたら `…` で切る**ようにしました（`RowSlot` は `shrink-0` なので、これまでは押し出されずに隣の列の上へ伸びていました）。③機材台帳の表で、チェックの列（自分で作った列の `checkbox`）が 1 本 128px を占めていたため、「検収／QR／Ver」を出すだけで **384px が空白**になり、そのぶん商品名が最低幅の 200px まで痩せて**機材名がどれも同じところで `…` に切れて**いました。チェックの列を 72px にし、商品名は**2行目までは出す**ようにしました（3行目以降は `…`。短い名前の行は今までどおり1行）。行の高さが2通りになるので、間引きの送り幅は見えている行の平均から測るようにしています。検証: `shared` の Vitest 1998件（新規2件を含む）、`server`/`client`/`client-daily`/`client-equipment` の型チェック、`npm run lint` すべて通過。

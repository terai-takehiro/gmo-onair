**メニューバー（左メニュー・アプリ切替）に出るアプリ名と、実際のページ自身が持つ見出し・タイトル
文字列が食い違う箇所を、6アプリ全件マルチエージェント調査で洗い出し、見つかった10件（うち凍結
済みの `client-awards` の1件を含めると11件）をすべて直した**。①案件管理・財務管理・カレンダー・
設定・GPMの5入口が同居する `client` で、利用マニュアルの見出しがどの入口から開いても常に
「案件管理 利用マニュアル」に固定されていたのを、いま開いている入口の名前に追随させた。②同じ
マニュアルの目次に改名前の旧名「スタジオ予約」（→カレンダー）「システム管理」（→設定）が残って
いたのを直し、削除済みメニュー項目「確定案件（スタジオ）」への案内も現行の「案件一覧」に更新した。
③GPM左メニュー「タスクと持ち帰り」・案件管理左メニュー「タスク一覧」がそれぞれの遷移先ページの
見出し（「全プロジェクトのタスク」「タスク」）と食い違っていたのを、メニュー側の名前に揃えた。
④設定アプリの先頭メニュー項目名がアプリ名と同じ「設定」のため上辺バーが「設定／設定」と重複
表示していたのを、共通シェル（`AppShell.tsx`）側でパンくずがアプリ名と同じ文字列のときは出さない
よう直し、他アプリでの再発も防いだ。⑤財務管理の左メニュー「取引先マスター（請求先）」を遷移先の
見出しに合わせて「取引先マスター」にした。⑥日常業務のホーム画面の見出しが左メニュー「ホーム」
ではなくアプリ名「日常業務」を名乗っていたのを「ホーム」に直し、フィードバックチケットの画面選択
プルダウンの「受領書類」を左メニューと同じ「受け取った書類」にした。⑦機材管理の機材台帳で、
左メニュー「貸出対象の機材」（`?view=lend`）から開いても見出しが常に固定文字列「機材台帳」の
ままだったのをタブに応じて動的に切り替え、印刷ダイアログの表題初期値が改名前の「機材一覧」の
ままだったのも「機材台帳」に直した。⑧凍結・配信停止済みの `client-awards` で、ランキング演出
画面が自分自身をアプリ名「リアルタイムCG」（スマホは英語「Ranking」）と名乗り、他画面からの
案内「ランキングCG」と食い違っていたのを「ランキングCG」に統一した。制作技術支援・計時・視聴者の
2アプリは調査の結果、食い違いは見つからなかった。

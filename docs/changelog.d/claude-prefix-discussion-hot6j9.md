2026年10月の事業再編（計上会社・案件番号の改番）で先に決めていたコンテンツスタジオ（グループ外案件の計上会社）の接頭辞コードを「GJV」から「SCS」に変更した。GSS（サムライスタジオ）・GMO（グループ本体）は変えていない。設計文書（docs/reorg-2026-10-plan.md）と、既に main にマージ済みだった実装（型定義・MCP ツールの entity_code enum・案件番号採番・隔週キープの計上会社別集計・社内取引・案件詳細/財務のUI表示・関連テスト・ドキュメント）を全面的に GJV→SCS へ置き換えた。DB 側は既存マイグレーション（284〜291）を書き換えず、新規マイグレーション `293_rename_gjv_to_scs.sql` で `legal_entities`／`money_rules`／各帳簿の `entity_code`／`companies.legal_entity_code`／`sequences.seq_name` を安全に改名するようにした（`companies.id = 'comp-self-gjv'` という主キー文字列自体は変えていない）。検証: `npx tsc -b server client client-daily`・`npm run lint`・`npm run test`（shared Vitest 2240件）いずれも通過。`npm run verify:up` で検証用DBを作り直し、migration 1〜293 の通し適用と `legal_entities`/`money_rules`/`companies` の実データが正しく `SCS` にリネームされていることを確認した。あわせて、社内取引作成（`createIntercompanyPurchase`）の金額検証が `Infinity`（非有限）や 0.5円のような1円未満の端数（sub-yen）を弾けていなかった既存の穴（`amount > 0` だけの判定）を、`Number.isFinite`・`Number.isInteger` を足して塞いだ（CI のレビュー検査で検出）。

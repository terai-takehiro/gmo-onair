**制作技術支援のトップページ（`/qsheet/top`）を iOS/macOS の作法で作り直したモックを作った**（コード変更なし・設計の探索）。
いまの画面は「案件管理の番組・イベント」と「ここだけの番組」の2つの一覧を素の枠線で
縦に並べているだけで、開いた瞬間に目が止まる場所が無かった。Claude Design のキャンバスに
PC2枚・スマホ2枚のアートボードを置き、クリックできる試作にした（さがす・絞り込み・
アーカイブの出入り・「番組を作る」のシート・ハブの折りたたみ・ピン・「次に決めること」の
無視が実際に動く）。
変えたのは5点: ①直近の本番・収録を最上段に置く（きょう＝青・あす・今週）
②「続きから」（最近開いたもの）で1タップで戻れるようにする
③2つの一覧を1つの表にまとめ、案件／ここだけはセグメントで切り替える
④終わったもの（本番日の翌日以降）は自動でアーカイブへ入れ、一覧の最後から開く
⑤面・罫・角丸・押し心地を iOS の inset grouped list の作法にそろえる。
あわせて、**案件を選んだあとの「選ぶページ」（ハブ・`JourneyPage.tsx`）**も同じキャンバスに
作り直した（PC・スマホ）。実装の機能は1つも落とさず、ミニアプリのタイルを主役にし、
1日に6個並んでいた「決まった にする」「要注意 にする」のボタンを44pxの印に変え、
日ごとのカードを折りたためるようにした。
**PR #299 でマージされたレンタル機材検索ミニアプリも反映済み**（ハブのタイルが5枚になり、
PCは1行5列・スマホは最後の1枚を2列ぶんに広げる。件数は既存の予約リストAPIから出せる）。
色・書体・角丸は v4 トークンの実値をそのまま使い、新しい色は1つも足していない。
①②はサーバー側の追加が要るため（`/lookup/gls-options` が日付を返さない・閲覧履歴が無い）、
モック上のタブで消して見比べられるようにした。作業ファイルは
`docs/design/v4/mockups/native/qsheet-top/` に置き、キャンバスの URL は
`docs/design/v4/production-v4-native-mockups.md` に記録した。

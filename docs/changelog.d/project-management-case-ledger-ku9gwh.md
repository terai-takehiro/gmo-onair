**プロジェクト管理の一覧に、案件台帳と同じ「リスト／ボード」の見え方と並び替えを足した**。
①これまで `/gpm/projects`（プロジェクト一覧）は表の一覧だけで、案件管理の案件台帳
（`/sales/projects`）にある「見え方の切り替え」「並び順」が無かった。②案件台帳と**同じ考え方**
（同じ問い合わせの結果を並べ替えるだけ・件数と金額が食い違わない）で、リスト表示に加えて
ステージ別のボード表示（`GpmProjectBoard.tsx`）と、並び順（おすすめ順／見積金額が大きい順／
期限が近い順）を足した。③構築プロジェクトは同時に数十件の規模なので、並び替え・見え方の
切り替えは**画面側**で行う（サーバーへの問い合わせは増やしていない）。実施期間の絞り込み・
Excel入出力・スマホのシート化・並び替え時のアニメーションは案件台帳から持ち込んでいない
（件数が増えたら移す）。

②実際に反映されなかったのは**権限・役割**だけで、メニュー表示やボタンの出し分けが参照する
`AuthContext.permissions` が react-query の外（プレーンな state）にあり、保存後にこの値を
読み直す経路が一切無かったため。他人の権限を変えたときは「本人がログインし直すと効きます」と

③`AuthContext` に `refreshPermissions()` を新設して公開し、役割を直したとき（`RoleDialog`）と

古い権限のままにはならない。④他の設定画面（休日・お金のルール・通知・カレンダー設定・機材台帳の

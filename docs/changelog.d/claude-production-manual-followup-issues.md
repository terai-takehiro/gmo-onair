**運営マニュアルで報告いただいた3件の不具合を直し、体制図に木構造の分岐・顔写真を足した**。①「文字追加をクリックしてキャンパスに反映しない時がある」— 追加した文字ブロックは中身が空だと枠線も背景も持たず、選択もしないままだったため、置けているのに気づけなかった（実際には毎回ちゃんと置けていた）。置いた直後にその場で選択状態にした（`ManualCanvas`の複製 Ctrl+D と同じ扱い）。②「各ブロック（文字や組織図など）がマウス操作で自由に配置できない」— 表・体制図ブロックは選択中、中身のどこをクリックしても`pointerdown`を止めていた（入力欄の focus 争いを避けるため）が、選択枠自体は`pointer-events-none`で掴めないため、結果として選択済みの表・体制図を動かす手段が無くなっていた。止める範囲を入力欄・ボタンの上のクリックだけに絞り、それ以外の「地」の上のクリックは通すようにした。③「ヘッダー・フッターが編集画面では見えない」— 実際に刷るヘッダー（資料番号・状態・時点・ページ番号）は仕上がりプレビューでしか見えず、編集中にブロックとの重なりに気づけなかった。編集画面のキャンバスにも同じヘッダーをそのまま重ねて出すようにした（フッターという別の帯は設計上存在しないため、そちらは対象外）。④体制図は「階層は上下だけ」で、系統どうしの分岐を表せなかった。3案（木構造で分岐／系統ごとに横並び／自由配置＋手で線を引く）を見た目つきでお見せし、木構造で分岐を選んでいただいた。箱に「親」（自分より手前の階層の箱）を選べるようにし、選ぶと親の下に線でぶら下がる木として描く（SVG座標は使わず`flex`の入れ子＋固定太さの罫のみ）。⑤あわせて顔写真（`ManualOrgPerson.photoUrl`）を追加。「インクを使わない」の唯一の例外のため既定は非表示（`show.photo`で選ぶ）。出す前の検査の体制図の高さ見積りも分岐の積み増しぶんを数えるよう直した。検証: `npx tsc -b client-techops client server`・`npm run lint`（0 errors・warning 54件＝着手前と同じ）・`npm run test`（shared 2422件・server review 94件、全pass。分岐の高さ見積りの回帰テスト3件を追加）・`node scripts/check-file-size.mjs`（`ManualDetailPage.tsx`が400行の壁に触れたため`useManualDetailMutations.ts`へ通信処理を切り出した）。

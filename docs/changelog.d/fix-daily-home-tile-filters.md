**日常業務のホームで、「内覧会 来場予約」「セキュリティカード」タイルの件数バッジを押しても絞り込まれていない一覧が開いてしまう不具合を直した**（2026-08-24 監査 `docs/reviews/2026-08-24-logic-audit.md` で確定）。①「内覧会 来場予約」タイルの「今後 N組」バッジは `HomePage.tsx` が `isUpcoming` で絞り込んだ集合を数えていたが、遷移先の `InviewPage.tsx` は既定 `scope='all'`（全期間）で開くため、押すと過去の回まで含む全件が出ていた。②「セキュリティカード」タイルの「貸出中」「返却遅延」バッジも同様に、遷移先の `SecurityCardsPage.tsx` が既定 `filter='all'` で開くため絞り込まれなかった。いずれも遷移先に絞り込み条件を渡す口が無かったのが原因。`InviewPage`/`SecurityCardsPage` が `?scope=`/`?filter=` クエリパラメータを初期値として読むようにし（既存の `?card=` と同じ流儀）、`HomePage.tsx` のリンクから `/inview?scope=upcoming`・`/security-cards?filter=lent`（`lent` は `overdue` を含むため両方のバッジをカバーする）を渡すようにした。検証: `npx tsc -b client-daily`・`npm run test`（1461件）・`npm run lint` を確認済み。実ブラウザでの確認はこのセッションから行っていない。

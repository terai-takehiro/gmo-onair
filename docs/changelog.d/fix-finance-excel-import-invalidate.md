**財務管理（仕入・販管費・売上）で、Excel取り込みや入金記録をしても一覧が古いままになる不具合を4件直した**（多エージェント監査 `docs/reviews/2026-08-24-logic-audit.md` 由来）。①〜③ 仕入一覧（`PurchaseListPage.tsx`）・販管費一覧（`SgaListPage.tsx`）・売上一覧（`RevenueListPage.tsx`）は、いずれも一覧本体が引く react-query の鍵（`purchases-all`/`sga-list`/`revenues-all`）と、画面上部の `<ExcelToolbar>` が取り込み成功後に invalidate する鍵（`purchases`/`sga-expenses`/`revenues`）が食い違っており、前方一致にならないため Excel取り込みが成功しても一覧が反映されず、再読み込みするまで古い件数・金額のまま表示されていた。3画面とも `ExcelToolbar` の `queryKey` を一覧本体と同じ鍵に揃えた。④ スマホの「入金の確認」（`MobileCollect.tsx`）で入金を記録したときの invalidate も `['revenues']` のみで、案件詳細の売上ペイン（`['revenues','project',projectId]`）には前方一致で当たるが、財務③ 売上一覧（`['revenues-all',…]`）には当たらず、PCの財務画面へ戻ると入金前の未収のまま表示されていた。`['revenues-all']` も合わせて invalidate するよう直した。検証: `npx tsc -b client`・`npm run test`（1461件）・`npm run lint` を確認済み。実ブラウザでのExcel取込・入金記録の実機確認はこのセッションから行っていない。

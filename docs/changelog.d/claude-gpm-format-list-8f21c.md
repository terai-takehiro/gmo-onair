**プロジェクト管理（GPM）の「プロジェクト一覧」「タスクと持ち帰り」を案件管理と同じ作法に揃えた**（`docs/design/v4/mockups/gpm-format-alignment.html` delta 1〜6・20〜22。詳細・ダッシュボード・フォームは別PRで並行着手）。プロジェクト管理だけが旧世代のモックを見て作られており、絞り込み帯の組み方・URLへの状態の持たせ方・件数表示・見出しの文言が案件管理とずれていた。①絞り込み帯を専用の `FilterBar.tsx`（1段目40px・2段目36px固定高さ・各枠は幅を決め打ち）に切り出し、PC・スマホで同じ props を共有。②見え方（リスト/ボード）・状態・区分・並び順を `useState` から URLクエリ（`?view=` `?stage=` `?kind=` `?sort=`。キー名は案件一覧と統一）へ移した。③件数表示とページ送り（`PageNav.tsx`）を追加（1ページで収まる時も件数を出し、絞り込み中は「全」と言わない）。④一覧の表頭（見積・次のアクション）をクリックで並べ替えられるようにした（hoverで薄く矢印を出す。プルダウンの3値と同じ `sort` stateを共有）。⑤「絞り込みを外す」の戻り先をPC/スマホで「進行中・準備中」に統一（従来はPC「すべて」・スマホ「進行中・準備中」で不一致だった）。⑥サブタイトルを「件数 ・ 全員が同じものを見ています」に短縮し、方針説明は新設の「用語」ボタンへ移した。⑦タスクと持ち帰り（`/gpm/tasks`）の見出しを左メニューと同じ「タスクと持ち帰り」に統一（従来は「全プロジェクトのタスク」で押した先の名前が違っていた）。⑧タスクタブに検索欄と並び順プルダウンを追加（46件から目的の1件を探せるように。サーバーには絞り込み用のクエリが無いため画面側で処理）。タブの持ち方（`?tab=`）はユーザー判断により変更していない。機能は変えていない（Excel入出力は案件一覧側にサーバーの入出力実装があり GPM プロジェクトには同等の口が無いため、新規機能追加になるとして別タスクへ切り出した）。検証: `npm run typecheck`（client/client-daily/client-equipment/server 全通過）、`npm run lint` 全通過、`shared` の Vitest 全通過。

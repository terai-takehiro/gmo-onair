**制作技術支援（Qシート）の各ページでバラバラだった UI の作りを統一しはじめた**。「各ページのデザイン思想が統一されていない。フォントの太さやサイズ、ページ幅など」というご指摘を受けて全131ファイルを実測したところ、①ページ直下の枠（本文幅と左右余白）が8通り、②画面の名前 `<h1>` の書き方が11通り・14px〜24px、③文字サイズが生 Tailwind 535 か所 対 v4 の型スケール 430 か所、④`font-medium`/`font-semibold` が161か所（LINE Seed JP は 400/700/800 しか無いため黙って落ちる）、⑤角丸が生の段と役割名で混在、と割れていた。原因は凍結解除を段階的に進める過程で「v4化を通ったブロック」と「client-live から移植しただけ／旧Qシートのままのブロック」が同居したこと。まず画面の外枠を1か所で決める `<PageShell>`（幅は `full` / `narrow` の2段だけ・余白は案件管理と同じ `p-3 lg:p-6`）を共通部品に新設し、v4 の規律に「5. ページの外枠」を足した。あわせてページ側の `env(safe-area-inset-bottom)` 直書きが `p-*` の下余白に勝って 0px になっていた5画面の誤用も是正の対象にした。棚卸しとブロック分担は docs/reviews/techops-ui-unification-plan.md。

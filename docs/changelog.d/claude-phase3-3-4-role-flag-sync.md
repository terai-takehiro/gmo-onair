**顧客・仕入先を削除したとき、取引先マスターのロール表示が更新されないまま残る不具合を直した**（`customers`/`vendors` テーブル削除に向けた準備の一部）。`DELETE /customers/:id`・`DELETE /vendors/:id` は今まで `customers`/`vendors` 側だけを論理削除し、取引先一覧（`companies.is_customer`/`is_vendor`）はそのまま残っていたため、削除済みの顧客・仕入先が `取引先一覧` の「顧客」「仕入先」絞り込みに残り続けていた。削除操作自体が `companies.is_customer`/`is_vendor` も更新するよう変更し、削除した相手は一覧からも正しく消えるようにした。権限は既存の作成経路と対称（顧客削除は `sales:manager` 以上、仕入先削除は `budget:manager` 以上）で、権限の壁は越えていない。検証: `npm run typecheck` / `npm run lint` / `npm run test` OK、`npm run verify:up` の実DBで顧客のみ削除→仕入先ロールは維持→仕入先も削除→両ロールとも一覧から消えることを確認した。

制作資料に「スケジュール表」（当日の枠）を足した。会場×時間軸で当日の動きを1日1枚に置き、
拠点ごとのひな形（列・項目の組み合わせ）から流し込める（時刻が解決できない項目は落とさず
赤字で残す）。本番・リハーサル・収録の枠から進行台本をその場で作って結べる（枠の長さと
台本の合計尺は別々に持ち、差は並べて見せるだけで自動調整しない）。項目単位の楽観ロックで
同時編集を扱い、409になった項目だけを赤くして他の項目の編集は止めない。進行表からの逆引き
（`documents/:docId/schedule-items`）は表への共有がある人にしか返さず、返す型も
社長・副社長の分単位の所在が漏れないよう必要最小限に絞った。Excel書き出し（ExcelJSを新規に
追加・3シート・区分の色つき）にも対応した。ブレイクダウン（ロール数・行数・枠と台本の
差分）は数えた事実だけを返し、進み具合の判定式は持たない。`MINI_APPS`レジストリの
`schedule`を有効にし、左メニュー・トップの導線に出るようにした。

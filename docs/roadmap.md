## 決めたこと (2026-07-26)

| 論点 | 決定 | 理由 |
| --- | --- | --- |
| 14章の「やめる4項目」 | **グループ区分は やめない**。タグ / 教訓・学び / 案件種類(その他) は削除 | グループ区分 = **費用を分け合う請求**。グループ9社合同の株主総会などで現役 |
| 請求 (31章) と 入力を減らす (14章) の順 | **請求が先** | 締めには期限があり「間に合わなかった」が起きる。入力の重さは重いだけで止まらない |
| 隔週キープの出力 | **PDF のみ** (PowerPoint は作らない) | 投影も配布もPDFで足りる。その分を他の章に回す |
| リハーサルと本番の分離 (24c) | **不要**。デザインから削除依頼 | 分ける概念を持たない |

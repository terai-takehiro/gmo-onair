### 32章 合同案件で決まったこと (デザイン側の回答)

| 論点 | 決定 |
| --- | --- |
| 入口 | **お金 ＞ 合同案件**。既存の費用分けは 案件 ＞ お金 ＞「他の案件と分け合う」 |
| 2つの見分け方 | **「請求書が何枚出るか」**。1枚なら費用分け、参加社数ぶんなら合同案件。作成時に最初にこの質問を出す |
| 分け方 | 均等 (既定) / 割合 / 金額を直接。**端数の行き先を画面に出す** (既定は幹事・変更可) |
| 1社だけ直したとき | 合計と総額の一致を画面で示し、**合わないうちは出せない**。差額は「残りの社で割り直す」か「幹事に寄せる」 |
| 出したあとに1社抜けたとき | **取り消しの請求書を1枚出して**残りに配り直す。「取り消し済み」と出して履歴に残す |
| 呼び名 | 「合同案件」。「按分」は出さない |

**31章の請求のしごとは `revenues` を読んでいる**ので、合同案件の請求書もそのまま一覧に並ぶ
(= 32章を作るときに31章を作り直さない)。
